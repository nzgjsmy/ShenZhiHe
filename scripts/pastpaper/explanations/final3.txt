@@@Q 34 2021
**先由生物量柱狀圖推出食物鏈的營養級次序**（原卷圖：生物量 kg，B > C > D > A）：

```
        B（生物量最大）
        ↓  被 B 吃掉
        C
        ↓  被 C 吃掉
        D
        ↓  被 D 吃掉
        A（生物量最小）
```

**推理的兩步**：

**第一步：誰是生產者？**
生產者（自營生物）處於食物鏈的第一層。在陸生生境中，**生產者的生物量通常最大**（一棵大樹、一片草地），因為它是其他所有生物的能量來源。
→ **B 的生物量最大，所以 B 是生產者**（這也是第 33 題的答案）。

**第二步：其餘三者的順序怎麼排？**
在一條四層的食物鏈裡，營養級越高，能量經過的傳遞次數越多，**流失的能量越多**，支持的生物量就越少。
→ 依序為 **B > C > D > A**，即 A 是最高營養級（最頂端的捕食者）。

**現在看選項**：「若種群 D 的個體數目下降，會發生什麼事？」

- **A 種群 A 的個體數目會增加 —— 錯**。D 減少 → **A 的食物來源減少** → A 會因缺食而**減少**（甚至部分死亡），絕不會增加。
- **B 種群 C 的個體數目會減少 —— 錯**。D 是**吃 C 的**（C 被 D 吃）。D 減少 → C 的捕食者變少 → C 的天敵壓力下降 → **C 的數目反而會增加**（這是「捕食者釋放被捕食者」效應），不是減少。
- **C 供應種群 A 的能量會減少 —— 正確**。A 以 D 為食（食物鏈為 B → C → D → A），D 是供應 A 能量的一環。D 個體數下降 → 送入 A 的能量（獵物）**減少** ✓
- **D 供應種群 C 的能量會增加 —— 錯**。D 減少，供應 C 的能量是 C **消耗** D 而來，D 少了，C 能得到的能量只會**減少**。

→ **C**。

**本題的判題關鍵 —— 題目問的是「能量」，不是「個體數目」**：

```
選項 A、講的是「個體數目」的變化（考的是捕食關係的方向）
選項 C、講的是「供應…的能量」的變化（考的是能量傳遞鏈的斷點）
```

「供應 A 的能量減少」是**最直接、最沒有爭議**的推論：D 是 A 的食物，D 少了，供給 A 的能量當然減少。至於各物種數目的具體變化，還牽涉出生率、死亡率、競爭等更多因素，因此 D 選項雖然方向可能反了，但 A 選項「增加」是明確錯誤的。

**易錯點**：以為「捕食者減少 → 被捕食者減少」。實際情況相反 —— **天敵減少，被捕食者會增加**（這是生態學中「頂級捕食者效應」的基本概念，狼被獵殺後鹿群暴增就是同一原理）。

**配套的資源量概念**：能量沿食物鏈**單向流動、逐級遞減**（約 10% 法則）。所以「供應 A 的能量」只能來自 C → D → A 這一條路徑，D 一減少，A 的能量供應必然下降。

**先認清三條血管**（原卷圖：肝臟、小腸與三條血管 X、Y、Z）：

```
                 血管 X  ──►（從右側流入肝臟）──►  肝  ──► 血管 Z ──►（流出）
                          ▲                              │
                          │                              │
              （從小腸來） └──── 血管 Y ─────────────────┘
```

- **X = 肝動脈**：從主動脈分出，把含氧血**送入**肝臟。
- **Y = 肝門靜脈**：從**小腸**（及胰、脾等）把剛吸收的養分送**入**肝臟。
- **Z = 肝靜脈**：把肝臟處理過的血**送出**，匯入下腔靜脈回右心房。

**再逐條分析空腹（禁食）時的血糖濃度**：

| 血管 | 空腹時的情況 | 血糖 |
|---|---|---|
| **X（肝動脈，進肝前）** | 來自主動脈，是全身的**基礎血糖**（約 5 mmol/L 的正常值） | 正常值 |
| **Y（肝門靜脈，進肝前）** | 此時腸腔**幾乎沒有養分被吸收**，門靜脈血幾乎不含新吸收的葡萄糖 | **很低** |
| **Z（肝靜脈，出肝後）** | 肝細胞正**消耗葡萄糖合成肝糖原**（把血糖「存起來」），血中葡萄糖被大量動用 | **最低** |

**所以 X > Y > Z** → **D**。

逐項檢查：

- **A Z > Y > X**：完全相反。
- **B Y > X > Z**：誤以為門靜脈血糖最高（那是**飯後**才對 —— 飯後腸腔吸收大量葡萄糖，門靜脈血糖會短暫高於動脈血）。
- **C Z > X > Y**：誤以為肝靜脈血糖最高（忽略了肝臟在儲存葡萄糖）。
- **D X > Y > Z —— 正確** ✓

**兩組對照，記住就不會搞混**：

| | 空腹（禁食） | 餐後（消化中） |
|---|---|---|
| 肝動脈 X | 基礎值 | 基礎值 |
| **肝門靜脈 Y** | **最低**（沒吸收） | **最高**（剛吸收大量葡萄糖） |
| 肝靜脈 Z | 最低（肝臟在合成肝糖原，消耗葡萄糖） | 較高（肝臟把糖釋出） |

**延伸（這是肝門循環的意義）**：
肝門靜脈讓消化道吸收的養分**先經肝臟處理**才進體循環 —— 肝臟可以隨時調節血糖（存糖或放糖），並且是**第一道解毒關卡**（藥物、酒精、氨都在此被處理）。

@@@Q 26 2022
**先記住卡爾文循環裡的兩種碳化合物**：

```
CO₂ （1 個碳）
   │  +  RuBP（5 個碳，稱為「5-C 化合物」）
   │  由 Rubisco 催化
   ↓
2 分子 3-PGA（「3-C 化合物」，含 3 個碳）
   │  用 ATP 與 NADPH 還原
   ↓
G3P（3 個碳）→ 一部分用來再生 RuBP（5-C）
```

**再看題目的情境：CO₂ 濃度由 1% 轉為 0.03%**（大幅下降）。

```
CO₂ ↓（底物減少）
   ↓
碳固定速率 ↓（Rubisco 拿不到足夠 CO₂）
   ↓
① 5-C 化合物（RuBP）的**消耗**減少 → 濃度**上升**
② 3-C 化合物（3-PGA）的**生成**減少 → 濃度**下降**
```

**注意「初期變化」**：光反應仍在正常進行（光照不變），ATP 與 NADPH 供應正常，所以**再生 RuBP 的能力不變**；變的是「消耗」端。

逐項檢查：

- **A 3-C 化合物減少 —— 3-C 化合物的還原減少**：前半句對（3-C 確實減少），但**解釋錯了**。3-PGA 減少是因為**碳固定減少**（生成少了），不是因為「還原」減少 —— 還原步驟所需的 ATP/NADPH 並沒有變少。
- **B 3-C 化合物減少 —— 光化學反應產生的 ATP 減少**：解釋錯了。題目只改變了 CO₂ 濃度，**光照不變**，光化學反應照常，ATP 產量不變。而且即使 ATP 減少，影響的也是還原步驟，3-PGA 是**生成**減少，方向對不上。
- **C 5-C 化合物濃度上升 —— 碳固定減少 —— 正確**。RuBP 的消耗（被用去固定 CO₂）變少，而再生不變 → RuBP 累積、濃度上升 ✓
- **D 5-C 化合物增加 —— 5-C 化合物的再生增加**：解釋錯了。**再生 RuBP 需要 ATP 和 NADPH，而這兩者來自光反應，光照不變所以再生速率不變**。真正變的是「消耗減少」，不是「再生增加」。

→ **C**。

**易錯點（這題的陷阱）**：
- 以為「CO₂ 少 → 碳固定增加」—— **恰恰相反，CO₂ 是碳固定的底物，底物少則固定慢**。
- 把「5-C 化合物上升」歸因於「再生增加」—— 再生不變；上升是因為**消耗（固定）變少**，一邊不減、一邊少用，就累積了。

**一句話記住**：
```
CO₂ ↓ → 固定 ↓ → RuBP 用不掉 → 5-C 累積上升
                → 3-PGA 產不出 → 3-C 下降
```
這是「**底物受限**」的典型表現，也解釋了為什麼在溫室裡要施 CO₂ 肥 —— 施多餘的 CO₂ 正是為了把 RuBP 轉成糖。
