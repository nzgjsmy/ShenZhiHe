@@@Q 9 2021
**這題考「對照組的設計」**。要證明「澱粉酶對澱粉的作用」，必須能**把結果歸因於酶**。

判斷標準：**兩個試管之間只差一個條件，且那個條件正是「酶」或「受質」**。

設想三支試管的典型設定：

```
P：澱粉 ＋ 澱粉酶   （完整系統）
Q：澱粉 ＋ 澱粉酶（經高溫處理失去活性）  或  澱粉 ＋ 蒸餾水
R：蒸餾水 ＋ 澱粉酶（或無澱粉）
```

- **比較 P 和 Q —— 可以**。P 與 Q 只差「酶是否有活性」，若 P 的澱粉被分解而 Q 的沒有，就能把效果歸因於**澱粉酶的作用** → ✓
- **只比較 Q 和 R —— 不行**。若 Q 與 R 都缺少關鍵條件（都沒有可作用的酶或都沒有澱粉），兩者結果相同，無法說明任何事。
- **三管一起比較 —— 不行**。必須是**兩兩配對**比較才能 isolating 單一變因；混在一起看無法確定差異來自哪一個變因。

→ **A（只有 P 和 Q）**。

**實驗設計的核心原則（考試通用）**：

```
① 一次只改一個變因
② 必須有對照組，且對照組與實驗組只差一個條件
③ 結論不能超出實驗證據能支持的範圍
```

**易錯點**：以為「三管都比較」更全面。事實上**同時比較會引入多個變因**，反而無法歸因；正確做法是選出**只有一個變因不同**的那一對。

**先問一個好問題：一天喝下 2 L 水，其中有多少會留下？**

答案是：**小腸吸收了絕大部分**。

```
水在大腸的功能：把剩餘的水分吸收掉，製造成形糞便

|---|---|---|

        ↓
① 促進細胞攝取與利用葡萄糖   → 血糖下降
② 促進肝糖原合成（肝與肌肉）→ 血糖下降
③ 促進多餘的葡萄糖轉變成**脂肪**貯存 → 血糖下降
```

也就是說，血糖高時身體要做三件事：**用掉、存成糖原、存成脂肪**。

逐項檢查：

- **A 葡萄糖的利用會增加 —— 對**。胰島素促進細胞對葡萄糖的攝取與代謝（尤其肝細胞與肌肉細胞），血糖因此下降 → ✓
- **B 脂肪轉化為糖原的情況會增加 —— 不正確（答案）**。方向完全相反：
  - 血糖**高**時：多餘的葡萄糖 → **脂肪**（脂肪合成增加）
  - 血糖**低**或**飢餓**時：脂肪分解成脂肪酸與甘油 → 脂肪酸供能、甘油**轉成葡萄糖**並進一步合成糖原（**糖質新生**）

  所以「脂肪 → 糖原」是**低血糖時**的代謝方向，本題問的是血糖**高**的時候 → ✗
- **C 血糖轉化為脂肪的情況會增加 —— 對**。胰島素促進脂肪合成，把多餘的糖以脂肪形式貯存（這也是為何長期吃太多碳水會發胖）→ ✓
- **D 血糖轉化為糖原的情況會增加 —— 對**。胰島素促進**肝糖原**與**肌糖原**的合成，把血糖暫時貯存起來 → ✓

→ **B**。

**兩種激素的完整對照（必背）**：

| | 胰島素（血糖高時↑） | 高血糖素（血糖低時↑） |
|---|---|---|
| 血糖 | **降低** | **升高** |
| 葡萄糖利用 | 促進 | 抑制（留給腦） |
| 肝糖原 | **合成** | **分解** |
| 脂肪 | **合成** | **分解** |
| 糖質新生 | 抑制 | 促進 |

**易錯點**：以為「高血糖素＝升血糖，所以它促進肝糖原合成」—— 高血糖素是讓肝臟**把糖原拆開賣出去**，方向與胰島素完全相反。

@@@Q 30 2021
**先釐清這個實驗在量什麼**：

```
每天中午記錄盆栽的重量
        ↓
重量下降 = 植物失去的水分 = 蒸騰作用造成
        ↓
蒸騰越強 → 重量下降越快（斜率越陡）
```

題目問「增加相對濕度的結果」是哪條線。

**關鍵推理**：相對濕度 = 空氣中水蒸氣的含量。

```
空氣濕度 ↑  →  葉片表面與空氣之間的水蒸氣濃度差 ↓
            →  水蒸氣擴散出葉片的速率 ↓
            →  蒸騰速率 ↓  →  失水變慢  →  重量下降最慢（線最平緩）
```

再看圖中各線的斜率（依原卷圖）：**Q 線最平緩**（下降幅度最小），P 雖然起點最高但斜率並非最小，R 與對照相若，S 下降最陡。

逐項檢查：

- **A P**：位置最高但斜率不是最平緩的 —— 起始重量高不代表蒸騰慢。而且**起始高度受初始條件影響**，判斷蒸騰速率應看**斜率**（下降的快慢），不是絕對高度。
- **B Q —— 正確**。Q 線斜率最平緩 = 失水最少 = 蒸騰最慢 = 相對濕度最高 ✓
- **C R**：斜率與對照相近或略陡，不是最平緩的。
- **D S**：下降最陡 = 蒸騰最強 = 對應的是**增加氣流**或**提高溫度**（或光照增強）。

→ **B**。

**四個環境因素對蒸騰的影響（同一套邏輯）**：

| 條件 | 對蒸騰的影響 | 機制 |
|---|---|---|
| **相對濕度 ↑** | **減弱** | 葉內外水蒸氣濃度差縮小 |
| 氣流 ↑ | 增強 | 帶走葉片周圍的水蒸氣，維持濃度差 |
| 溫度 ↑ | 增強 | 水分蒸發加快、氣孔開度增大 |
| 光照 ↑ | 增強 | 氣孔開啟（蒸散拉力）、葉溫升高 |

**易錯點（極重要）**：用「線條的**位置高低**」判斷蒸騰強弱。位置高低只反映**起始重量**；蒸騰速率要看**斜率**。這與 PP Q19 海草題是同一個教訓。

@@@Q 31 2021
**先想清楚：這個實驗要量的是「植物因蒸騰而失重」，那有什麼會干擾？**

```
理想情況：重量減少 ＝ 植物蒸騰失水
        ↓
但還有別的水分流失來源：
        ✗ 土壤表面直接蒸發水分
        ✗ 落葉本身失重
        ✗ 澆水改變重量
```

逐項檢查：

- **A 移除任何掉落的葉 —— 不必要**。落葉的重量很小，而且**移除它反而會讓數據更亂**（每稱一次就要動植物）。更關鍵的是：**落葉也會蒸騰**，但它掉落後不再計入盆重，其失水已自然包含在重量變化裡 —— 不需要特別處理。
- **B 用塑膠袋包裹花盆 —— 正確（必要）**。這是**必需的步驟**：塑膠袋封住花盆表面，**阻止土壤水分蒸發**，於是「重量減少」就**只反映植物的蒸騰**。
  若不包裹，量到的是「植物蒸騰 ＋ 土壤蒸發」的總和，而土壤蒸發量可能遠大於植物蒸騰 —— 實驗就失去意義了 ✓
- **C 每天早上為植物澆水 —— 錯誤且不可行**。澆水會**大幅改變重量**（一次澆水就增加幾百克），完全淹沒蒸騰造成的重量變化，使數據無法比較。
- **D 在葉的下表皮塗上凡士林 —— 錯誤**。塗凡士林會**堵塞氣孔**，直接阻斷蒸騰的通道 —— 那等於把要研究的現象本身消除了，實驗失去意義。

→ **B**。

**控制變項的思路（推而廣之）**：

```
研究「植物蒸騰失水」→ 需要確保「唯一的水分流失途徑就是葉片蒸騰」
→ 封住土壤表面（塑膠袋）
→ 不澆水、不改變葉面積、不堵塞氣孔
```

**易錯點**：以為「越嚴格越好」就多加步驟。像「每天澆水」這種會**引入新變數**的操作，是把實驗毀掉而不是保護它。
