## 4. 这一轮学到的（下次别再踩）

1. **超高解析扫描要先缩图再看**：2024 P2 是 6667×9425，直接交给视觉模型会「图太大被丢弃」。
2. **A3 双页 MS 要裁半页读**：2024 MS 是中英双语并排，整页读字太小，按 x 0.01–0.52 / 0.51–0.99 裁开。
3. **`verify_build.py` 只查图片引用**：字体、manifest 图标这类相对路径资源查不到 ——
   这次就是靠它漏掉了「标题字体线上 404 近一个月」。（不过 11-24 已把字体整套删了，现在全站系统字体。）
4. **部署包 push 前先 `git merge --ff-only origin/main`**：远端会被 daily-news 定时任务推进；
   那次自动部署还删过 116 张图，全量 `rm -rf img && cp -r` 正好补回来。
5. **分值双向核对有效**：2024 Q3 小问合计 21 vs 题末 20，放大原卷发现 (b)(ii) 是 1 分不是 2 分。
