# 數學卷二甲部／乙部（MC）真題庫 + 答案表

日期：2026-11-27　作者：WorkBuddy　分支：source

## 目標

用戶要兩件事：
1. 數學分區要有 **Paper 2（MC）的 DSE 真題庫**；
2. **額外資訊**要有一份 **答案表**，按年份 → 題號排序，並按答對率分色。

## 一、素材實況（先摸清楚，別急着寫代碼）

`DSE Past Paper（持續更新中）/3. 數學/<年份>/` 每年有 P1、P2、MS（評卷參考）、CP（考生表現）。
關鍵發現：

| 項目 | 實況 |
|---|---|
| P2 有沒有文字層 | **幾乎都沒有**。只有 2015 有 6040 字，其餘全是掃描圖（2012 只有 34 字） |
| 解答在哪 | 各年《評卷參考》**最後一頁**有「試卷二」答案表：題號／答案／(答對百分率) |
| 2014 排版 | **跨頁拼版**：每張 PDF 頁 = 左右兩個印刷頁（1191×842），要按中縫切開、左先右後 |
| 2018 排版 | **沒有封面頁**，第 1 張 PDF 頁就是正文（Q1–Q3），不能固定跳過第 1 頁 |
| PP（練習卷） | 只有 P1，**沒有 P2** |
| SP（樣本卷） | 有 P2 但**沒有評卷參考**，45 題答案無從核對，先不收 |
| **2024** | `2024 MS+CP.pdf` 只有**卷一**評卷參考 + 考生表現，**沒有卷二答案表** → 2024 暫缺 |

## 二、答案表（已完成，13 年 585 題）

工具：`scripts/pastpaper/math_p2_answers.py`

做法與踩坑：
1. rapidocr 掃 MS 最後幾頁，把「題號」與「答案 (百分比)」配對。
2. **配對必須按行分組再配**：先用固定 x 分欄（0.55W）會把右欄題號判成左欄，
   2012 Q19、2013 Q45 都因此配錯。改成「同一行（y 差 <16px）內，答案在題號右側最近」。
3. `used` 集合要**每行重置**，否則第一行用掉 index 0 之後，後面所有行都當成「已佔用」。
4. 條帶／整頁 OCR 都會漏認題號，所以還有第二重保險：**欄內 y 序重建**
   （左欄 25 個答案依次對 1–25，右欄 20 個對 26–45），只補漏不覆蓋已配對結果。
5. **OCR 結果不能直接信**：它會整段錯行（2020 Q27–Q30 整排往前挪一格）。
   最終做法是逐頁用視覺模型重讀放大後的表格，與 OCR 交叉比對，全部 13 年 585 題人工核對過。
   核對後的答案寫在 `scratch/mathpp/truth.txt`，再由 `math_p2_dataset.py` 轉成 JSON。

答對率分級沿用站內真題頁的四級：≥80 容易／60–79 中等／40–59 偏難／<40 極難。

## 三、真題庫（8 年 360 題，其餘待補）

因為 P2 是掃描件、公式與圖形密集，**逐題轉文字必然失真**（分式、根號、指數全會爛），
所以題庫走「**原卷題圖**」路線：每題裁一張原卷區域圖，前端只給 A/B/C/D 字母按鈕，
答對率與答案照樣可對。前端本來就支援這種形式（`qImg` + 字母按鈕），這次只加了一個
`qImgNote` 欄位讓文案可以換成數學的說法。

工具：`scripts/pastpaper/math_p2_build.py` → `site/img/pp/math/<年>/qNN.webp`

### 已收錄（45 題齊全）

2013、2014、2016、2017、2019、2020、2023、2025

### 未收錄（題號偵測不齊，下一輪修）

2012（41/45）、2015（43/45）、2018（44/45）、2021（38/45）、2022（44/45）、2024（無答案表）

### 題號偵測為什麼難

* 題號常與題幹糊成一個 OCR token（`34.若 x…`），所以不能只認「恰好等於 34.」；
  要用 `^(\d{1,2})[.．](?!\d)` 這種「以題號開頭」的規則。
* 公式裡的數字會被誤認成題號（2016 曾把 `34.` 認在很前面，導致真正的 34–45 全被單調校驗擋掉）。
* 用「行首貼左邊距」補漏時，若補到選項行，會裁出**只有一行選項**的廢圖
  （2015 Q8–Q11 就是這樣），所以補漏時要排除「距上一題開頭不到 150px」的候選行。
* 200dpi 對多數年份最準；2015 反而要 150dpi。腳本支援 `MATHPP_DET_DPI` 覆蓋。

## 七、上线时踩到的坑（务必记住）

`site/prep_ghpages.py` 的图片白名单是正则：

```python
r"img/(pp/(?:chem/)?(?:[0-9]{4}|PP|SP)/[A-Za-z0-9_]+\.webp)"
```

只认 `img/pp/<年>/` 与 `img/pp/chem/<年>/`。数学题图放在 `img/pp/math/<年>/qNN.webp`，
**整批 360 张没被复制进部署包**，而 `verify_build.py` 只查 `site/img/` 里有没有这张图、
不查部署目录，所以一路全绿 —— 线上会整页破图。

已改成 `(?:(?:chem|math)/)?`。**以后新增科目子目录（phys/…）时必须同步改这条正则。**
自查方法：`find gh-pages/img/pp/<科目> -name "*.webp" | wc -l` 应等于题数。

## 八、2024 補入（V0.25.26.1）

用戶提供了 2024 年「試卷二」答案表截圖（官方 `2024 MS+CP.pdf` 只有卷一評卷參考＋考生表現），
答案已錄入 `scratch/mathpp/truth.txt`，2024 的 45 題裁圖也一併入庫。

2024 的坑與其他年份不同：
* 原卷掃描解像度是 **1096×1548 pt**（其他年份 595×842），200dpi 出來是 3034×4345 px；
* 這個尺寸下整頁 OCR 會把題號「1.」當噪聲丟掉（第 2 頁只認到題幹，`1.`／`2.`／`3.` 全無），
  但把左邊界切一條 **x 230–420** 的窄條單獨 OCR，三個題號立刻回來；
* 所以 `math_p2_build.py` 的條帶寬度改成按頁寬比例（`max(90, 6%W)`），並支援
  `MATHPP_STRIP="230,420"` 指定絕對範圍：

```bash
MATHPP_STRIP="230,420" python scripts/pastpaper/math_p2_build.py 2024
```

* 裁圖另外加了寬度上限 1300px（2024 原尺寸的圖會是別年的 1.8 倍，不壓檔案會爆）。

結果：題庫 **9 個年份 405 題**，答案表 **14 個年份 630 題**。
