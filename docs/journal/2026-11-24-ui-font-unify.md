# 全站字体回默认 + 首页 DSE 卡改 MC / LQ（V0.25.25.26）

> 2026-11-24 18:40 · WorkBuddy · 用户反馈驱动

## 用户说的是什么

「现在网站每一个字的字体风格都不一样，帮我变回默认的字体风格」，并附图：
首页两张 DSE 卡「卷一 · MC」「長題目 · 卷一乙部 ＋ 卷二」，要求「卷一和卷二的按钮文字分别改成 MC 和 LQ，生物分区也是」。

## 字体为什么突然「花」了

不是新问题，是**修好 404 之后才暴露的旧问题**：

- 上一轮（18:10）才发现标题字体 `fonts/LongCang-Title.woff2` 在线上一直 404 —— 意味着自 2026-10-30 以来，
  线上标题其实一直是**系统字体回退**，所有人都没见过龙藏体真正的样子。
- 18:10 补上字体文件后，龙藏体真的加载了：`.hero h1`、`.thead h2`、`.hn-hand`、`.dse-hero .tx b` 变手写体，
  `--hn-serif` 让卡片标题/仪表盘数字走宋体，正文是黑体 —— 三套字体同屏，就是用户说的「每个字风格都不一样」。

## 改法

全部在 `site/template.html`，原则是「删覆盖、不删结构」：

| 位置 | 原来 | 现在 |
|---|---|---|
| `@font-face` | Long Cang | **删除**（连 15 行说明注释一起换成「全站统一系统字体」的说明） |
| `.hn-hand`（页头碎念） | `"Long Cang","Noto Serif TC",serif` | 删掉 font-family，继承 |
| `.hero h1`（首页大标题） | 龙藏体 32px / 400 | 继承 + **700** |
| `.thead h2`（各页标题） | 龙藏体 30px / 400 | 继承 + **700** |
| `.dse-hero .tx b`（DSE 卡标题） | 龙藏体 24px，line-height 1.55 | 继承 + 700，line-height 回 1.4（1.55 是为手写体的 ascent 留的） |
| `.qtext`（题目正文） | `"Noto Serif TC",serif` | 删掉，继承 |
| `--hn-serif` | `"Noto Serif TC","Songti TC","Long Cang",serif` | 指向 body 的无衬线栈（**名字不改**，10+ 处引用自动生效） |

`--hn-serif` 那条是关键：它叫「serif」但已经不是衬线体了，名字留着是因为引用太散（卡片标题、`.dash-num`、
`.subcard h3`、`.opt` 文案等）。注释里写清楚，免得后人以为漏改。

**为什么要改 font-weight**：400 是给手写体配的（龙藏体本身笔画粗、带笔锋）。换成系统黑体后，46px/30px 的 400
在浅底上会发灰发虚，必须 700 才「立得住」。

## 卡片文字

```diff
-<b>卷一 · MC</b>
+<b>MC</b>
-<b>${LQ_P1_ONLY?'卷一乙部 · 長題':(LQ_BOTH?'長題目 · 卷一乙部 ＋ 卷二':'卷二 · LQ')}</b>
+<b>LQ</b>
```

副标题保留信息量，并且顺手修了「只有卷一乙部」的科目（原本副标题写「N 個年份 · N 道大題」，会让人以为是完整的卷二）：
现在 `LQ_BOTH` → 「卷一乙部 223 道 · 卷二 45 道」；`LQ_P1_ONLY` → 「卷一乙部 N 道」。aria-label 同步。

生物/化学/物理共用同一段代码，所以「生物分区也是」自动满足，不需要分科改。

**没动的地方**：LQ 页里的两个二级切换（「📄 卷一 · 乙部」「📚 卷二 · 長題」）保持原样 ——
卷一乙部本身就是**长题**，标成 MC 会误导（生物卷一乙部 142 道全是 LQ）。如果用户想要的就是这两个按钮，再单独改。
