# 2026-10-30 · 用官方《評卷參考》校對卷二 LQ 分值（V0.25.3）

> 起因：V0.26.0 起 LQ 参考答案 106/106 写完，但**分值全是按学科判断 + DSE 惯例推的**，
> 不是官方的。题解稿里有 37 处明确标了「分值待核對」，库里还有 8 个子题分值空着。
> 本轮把官方《評卷參考》挖出来，用它逐题逐小题核对。

## 一、坑：官方参考 PDF 里卷一卷二混在一起

`D:/生物DSE Past Paper/<年份>/<年份> 参考答案.pdf` 的结构是：

```
p001        卷一 MC 答案表（题号 | 答案 | 答对率）
p002..pNN   卷一评分参考（乙部、卷一的大题…）
pNN..       封面「生物 試卷二 BIOLOGY PAPER 2」
pNN..       評卷參考 · 一般評卷指引
pNN..       卷二评分参考（甲部/乙部/丙部/丁部）
```

一开始把 p002–p005 当成了卷二，结果**题号对不上**，一度以为「年份错位」。

**判定卷二页的可靠依据**：页内有「卷二 / 試卷二 / PAPER 2」，或页脚形如
`PP-DSE-BIO 2-3`（卷一页脚是 `1-3`）。2012 的页脚只有页码，没有 BIO 编号，
靠页眉「卷二甲部」识别。

## 二、年份没错位——两个独立验证

1. **卷一 MC 答案表**：参考 PDF p001 的「题号 | 答案 | (答对率)」三列两栏排版，
   OCR 解析出 18 条，与 `data/bio/_mc_answers.json` 的 2012 命中 15/18
   （第 6 题是多答案题 `A~`，解析器漏了）。
2. **题干 bigram 匹配矩阵**：用中文 2-gram 重合度把 106 道大题的题干
   拿去匹配全部 156 页参考文本，2012/2019/2022/2023/PP/SP 都呈**强对角线**：
   2012 → p006–p009、2019 → p007–p010、2022 → p009–p012、2023 → p009–p015、
   PP → p011–p014、SP → p007–p011。

## 三、关键：VLM 读不出分值列，PaddleOCR-VL 这条路废了

评分参考**最右侧有一列孤立的小分值数字**（每个得分点右侧一个 `1`），这是判定
「每小题几分」的唯一权威来源（原卷只印大题总分）。

- **PaddleOCR-VL**：把整页读成语义块，**右列数字被整列吞进正文块，完全读不出来**。
  跑了 12 页才发现，白费约 46 分钟。
- **RapidOCR 整页**：能读出右列大多数，但会**成片漏整行正文**（p011 有一整行
  连 `(iii)` 带正文全没读出来）。
- **OpenCV 连通域**：不依赖识别，只按几何把右列的孤立数字抠出来 —— 最可靠。
  实测 PP p011：连通域 20 个、整页 RapidOCR 20 个，**y 坐标逐一对上**。

## 四、版式分两代，必须分别处理

| | 旧版（2012–2023、SP） | 新版（PP） |
|---|---|---|
| 得分点分值 | 印在正文里，**行末右列**另有 `(1)` | 只在右列，**裸数字** `1`/`2`/`2×2` |
| 小题满分 | 部分题印「**(最高 N)**」 | 无 |
| 题末总分 | 每道大题末尾独占一行印「**N 分**」 | 无 |

- 旧版正文与右列**都有** `(1)`，只能取右列那份，否则翻倍。
- 「(最高 N)」比逐得分点累加可靠：一个得分点占两行时，累加会多算 1 分。
- 页码（`43`/`46`…）在页脚，会被误当成题号，要单独剔掉。

## 五、工具链（`scripts/pastpaper/`）

| 脚本 | 作用 |
|---|---|
| `lq_vl_par.py` | VLM 多进程版（页粒度、可续跑）。**实测 4 workers 几乎不加速**（32G 内存跑不动 4 份模型），最终弃用 |
| `ref_layout_probe.py` | 探查各年份版式（统计「N 分」「(N)」右列数字各多少） |
| `ref_text_dump.py` | 156 页参考件 OCR 成纯文本存档 + 建题干↔页码匹配矩阵 |
| `ref_year_match.py` | 用卷一 MC 答案表（含答对率）核对年份 |
| `lq_ref_extract.py` | 从卷二页抽「题号 → part → 小题 → 分值」，小题**按出现顺序编号**（不信 OCR 读到的罗马数字，见下） |
| `lq_ref_apply.py` | 与 `_lq.json` 逐题逐小题比对、分级（FILL/CONFLICT/COUNT）、回填 |
| `lq_marks_diag.py` | 诊断题解稿与 `_lq.json` 的分值对齐情况 |

### 为什么小题要按顺序编号

RapidOCR 会把 `(ii)` 漏读成 `(i)`（2012 p007 里 y=543 的 `(ii)` 就被读成 `(i)`），
按标记字面匹配会把小题边界弄乱。改成**同一 part 内按出现顺序编号**后，
官方序列与我们 `_lq.json` 的 subqs 序列能稳定对上。

### 对齐口径踩过的坑

1. 早先只取「有分值或 level≥2」的条目当可计分子题 → **漏掉了大量官方小题**。
   2012 2(a) 的 `(i)` 恰好对应我们那条 level=1、没分值的条目
   （"階段 II → 階段 III 自然植被重現的過程"），滤掉就等于丢了 3 分。
   改成**一条都不滤**后，FILL 从 3 题涨到 13 题。
2. 我们库里把 `(i)` 下面的 `(1)(2)` 也列成独立条目（level=2），官方那边是
   一个小题 → 两边条目数经常对不上，只能靠**分段和**反推：
   `solve_blanks()` 枚举所有可行分段，取所有解的交集，只填**唯一确定**的空缺。
3. 官方 part 和 > 15 分基本是提取错乱（DSE 一个 part 一般 ≤ 12 分），
   2017 1(a)（19 分）、2023 1(a)（21 分）就是这么混进来的 —— 加闸门拦掉。
4. **官方只会漏读、不会多读**，所以「官方和 > 我们和」必然是我们漏了分，
   可以放心补；反过来不动（可能是官方漏读）。这条是整个回填的安全阀。

## 六、结果

- **补上 11 个原本空缺的小题分值**，同步修正 **11 道大题的 marksTotal**：
  2012 2(a) 9→12、2012 4(a) 4→8、2013 3(a) 8→11、2014 3(b) 5→8、
  2015 1(a) 9→11、2016 2(b) 8→10、2016 3(b) 6→10、2016 4(b) 10→11、
  2017 2(a) 8→12、2017 2(b) 7→8、2021 2(b) 8→10、2021 3(b) 11→15、
  2022 3(a) 8→10。
- 2012 2(a) 的 3 分缺口最典型：题解稿标着「(i) 階段 II → 階段 III 自然植被重現的過程
  （分值待核對）」，官方正是 3 分 —— **题解稿自己数得分点就能推出**，
  官方只是把它证实了。
- 官方总分 vs 我们收录总分：2012 70/67、2013 80/77、2015 80/75、2016 80/73、
  2017 79/73。**系统性偏低**，印证了「按惯例推的分值会漏给分点」。

## 七、还没做完的

- **新版式（PP／2020／SP／2018）一题都没抽出来**：`is_paper2` 判卷二页时漏了
  几页，且右列是裸数字，`MAXMK`/`MARK` 之外的形态没适配（`2×2` 乘法式、
  裸 `1` 无括号）。这是下一步。
- **46 题仍是 COUNT**（官方小题数与我们条目数对不上），需要逐题人工核。
- **数据缺口**：官方题号只到 4–5，2013/2015/2016 官方合计 80 分（DSE 卷二满分
  96），**说明这些年份的卷二原卷扫描件本身就缺题**（2012 原卷只有 9 页 4 道大题，
  2014 缺丁部）。评分参考能量化缺口，但补不上题干 —— 要重新扫描完整原卷。
- 官方评分参考的**得分点表述**还没拿来对照题解（这是提高题解质量的增值项）。

## 补记（V0.25.4）：卷二页判定是最脆的一环

第一版只按「页眉有『卷二』」判卷二页，结果三种坏情况轮番出现：

1. **整页搜「卷二」太宽松** —— 卷一的页面只要正文里引用到「卷二」二字就被误判
   （2018／2020／SP 的参考件页脚只有纯页码 `46`/`47`…，没有 `BIO 2-x`，
   全靠这个判据，于是整卷判错）。
2. **顶部 8 行太严** —— 有些卷二页页眉只是「甲部 人體生理學：调節與控制」
   （PP p011）或「乙部 應用生態學」（PP p012），不含「卷二」二字。
3. **匹配矩阵取并集 = 灾难** —— 矩阵对个别题会落到卷一页（PP 的 p005 就是卷一），
   并进来后卷一的题号（1、2、3…）顶掉卷二的题号，整卷题号体系错位。
   **实测 FILL 从 11 题掉到 1 题**，而且错得很隐蔽（很多题变成「官方=[]」）。

最终规则（三条同时成立才用）：
- 参考 PDF 里**卷一卷二相连**，卷二＝尾端一段**连续页**；
- **anchor** = 首个带卷别标记的页（页面前 8 行有「卷二/試卷二/PAPER 2」，
  或页脚 `BIO 2-x`），卷二页 = anchor（前后各扩一页）到 PDF 末页；
- 匹配矩阵**只在该区间内**做补充，**绝不取并集**；
- anchor 找不到（2018／2020／SP）才整段改用匹配矩阵的页（该年份自身、
  score ≥ 0.12、不前后扩展），再取连续段。

顺带修好 PP 页脚的两种写法：`PP-DSE-BIO 2--5`（双连字符）、
`PP-DSE-BIO2--6`（无空格）—— 旧正则 `BIO\s*2\s*-\s*\d+` 两个都不匹配。

**这一轮再补 3 题**：2012 2(b) 5→8（官方 (b)(i)=3，与我先前手工数得分点的结果一致）、
2023 1(a) 7→10、2023 3(b) 7→9。

**累计（V0.25.3 + V0.25.4）**：补上 14 个空缺小题分值、修正 14 道大题 marksTotal。

**新版式仍是 0 题**：PP／2020／SP／2018 的右列是**裸数字**与 `2×2` 乘法式
（不是旧版的 `(1)`），解析器的 MARK/MARKX 正则没覆盖到；且这些年份的
小题标记行首排版与旧版不同。这是下一步的活。

「回退翻頁」是**減**功能而非加功能，後面三個都是純內容／題庫補充 ——
按「字節級小改動 → V0.0.x」的規則，應該在 V0.25.0 之下逐個遞增，
而不是每改一次題庫就跳一個 V0.X.0。用戶指出後已全面重編，
`version.json` 的 note 裡每條都標註了「（原編號 V0.2X.0）」以保留追溯。
