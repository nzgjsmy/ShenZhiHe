# 2026-10-30 · 用官方《評卷參考》校對卷二 LQ 分值（V0.25.3）

> 起因：V0.26.0 起 LQ 参考答案 106/106 写完，但**分值全是按学科判断 + DSE 惯例推的**，
> 不是官方的。题解稿里有 37 处明确标了「分值待核對」，库里还有 8 个子题分值空着。
> 本轮把官方《評卷參考》挖出来，用它逐题逐小题核对。

## 一、坑：官方参考 PDF 里卷一卷二混在一起

`D:/生物DSE Past Paper/<年份>/<年份> 参考答案.pdf` 的结构是：

```
p001        卷一 MC 答案表（题号 | 答案 | 答对率）
p002..pNN   卷一评分参考（乙部、卷一的大题…）
pNN..       封面「生物 試卷二 BIOLOGY PAPER 2」
pNN..       評卷參考 · 一般評卷指引
pNN..       卷二评分参考（甲部/乙部/丙部/丁部）
```

一开始把 p002–p005 当成了卷二，结果**题号对不上**，一度以为「年份错位」。

**判定卷二页的可靠依据**：页内有「卷二 / 試卷二 / PAPER 2」，或页脚形如
`PP-DSE-BIO 2-3`（卷一页脚是 `1-3`）。2012 的页脚只有页码，没有 BIO 编号，
靠页眉「卷二甲部」识别。

## 二、年份没错位——两个独立验证

1. **卷一 MC 答案表**：参考 PDF p001 的「题号 | 答案 | (答对率)」三列两栏排版，
   OCR 解析出 18 条，与 `data/bio/_mc_answers.json` 的 2012 命中 15/18
   （第 6 题是多答案题 `A~`，解析器漏了）。
2. **题干 bigram 匹配矩阵**：用中文 2-gram 重合度把 106 道大题的题干
   拿去匹配全部 156 页参考文本，2012/2019/2022/2023/PP/SP 都呈**强对角线**：
   2012 → p006–p009、2019 → p007–p010、2022 → p009–p012、2023 → p009–p015、
   PP → p011–p014、SP → p007–p011。

## 三、关键：VLM 读不出分值列，PaddleOCR-VL 这条路废了

评分参考**最右侧有一列孤立的小分值数字**（每个得分点右侧一个 `1`），这是判定
「每小题几分」的唯一权威来源（原卷只印大题总分）。

- **PaddleOCR-VL**：把整页读成语义块，**右列数字被整列吞进正文块，完全读不出来**。
  跑了 12 页才发现，白费约 46 分钟。
- **RapidOCR 整页**：能读出右列大多数，但会**成片漏整行正文**（p011 有一整行
  连 `(iii)` 带正文全没读出来）。
- **OpenCV 连通域**：不依赖识别，只按几何把右列的孤立数字抠出来 —— 最可靠。
  实测 PP p011：连通域 20 个、整页 RapidOCR 20 个，**y 坐标逐一对上**。

## 四、版式分两代，必须分别处理

| | 旧版（2012–2023、SP） | 新版（PP） |
|---|---|---|
| 得分点分值 | 印在正文里，**行末右列**另有 `(1)` | 只在右列，**裸数字** `1`/`2`/`2×2` |
| 小题满分 | 部分题印「**(最高 N)**」 | 无 |
| 题末总分 | 每道大题末尾独占一行印「**N 分**」 | 无 |

- 旧版正文与右列**都有** `(1)`，只能取右列那份，否则翻倍。
- 「(最高 N)」比逐得分点累加可靠：一个得分点占两行时，累加会多算 1 分。
- 页码（`43`/`46`…）在页脚，会被误当成题号，要单独剔掉。

## 五、工具链（`scripts/pastpaper/`）

| 脚本 | 作用 |
|---|---|
| `lq_vl_par.py` | VLM 多进程版（页粒度、可续跑）。**实测 4 workers 几乎不加速**（32G 内存跑不动 4 份模型），最终弃用 |
| `ref_layout_probe.py` | 探查各年份版式（统计「N 分」「(N)」右列数字各多少） |
| `ref_text_dump.py` | 156 页参考件 OCR 成纯文本存档 + 建题干↔页码匹配矩阵 |
| `ref_year_match.py` | 用卷一 MC 答案表（含答对率）核对年份 |
| `lq_ref_extract.py` | 从卷二页抽「题号 → part → 小题 → 分值」，小题**按出现顺序编号**（不信 OCR 读到的罗马数字，见下） |
| `lq_ref_apply.py` | 与 `_lq.json` 逐题逐小题比对、分级（FILL/CONFLICT/COUNT）、回填 |
| `lq_marks_diag.py` | 诊断题解稿与 `_lq.json` 的分值对齐情况 |

### 为什么小题要按顺序编号

RapidOCR 会把 `(ii)` 漏读成 `(i)`（2012 p007 里 y=543 的 `(ii)` 就被读成 `(i)`），
按标记字面匹配会把小题边界弄乱。改成**同一 part 内按出现顺序编号**后，
官方序列与我们 `_lq.json` 的 subqs 序列能稳定对上。

### 对齐口径踩过的坑

1. 早先只取「有分值或 level≥2」的条目当可计分子题 → **漏掉了大量官方小题**。
   2012 2(a) 的 `(i)` 恰好对应我们那条 level=1、没分值的条目
   （"階段 II → 階段 III 自然植被重現的過程"），滤掉就等于丢了 3 分。
   改成**一条都不滤**后，FILL 从 3 题涨到 13 题。
2. 我们库里把 `(i)` 下面的 `(1)(2)` 也列成独立条目（level=2），官方那边是
   一个小题 → 两边条目数经常对不上，只能靠**分段和**反推：
   `solve_blanks()` 枚举所有可行分段，取所有解的交集，只填**唯一确定**的空缺。
3. 官方 part 和 > 15 分基本是提取错乱（DSE 一个 part 一般 ≤ 12 分），
   2017 1(a)（19 分）、2023 1(a)（21 分）就是这么混进来的 —— 加闸门拦掉。
4. **官方只会漏读、不会多读**，所以「官方和 > 我们和」必然是我们漏了分，
   可以放心补；反过来不动（可能是官方漏读）。这条是整个回填的安全阀。

## 补记（V0.25.4）：卷二页判定是最脆的一环

第一版只按「页眉有『卷二』」判卷二页，结果三种坏情况轮番出现：

1. **整页搜「卷二」太宽松** —— 卷一的页面只要正文里引用到「卷二」二字就被误判
   （2018／2020／SP 的参考件页脚只有纯页码 `46`/`47`…，没有 `BIO 2-x`，
   全靠这个判据，于是整卷判错）。
2. **顶部 8 行太严** —— 有些卷二页页眉只是「甲部 人體生理學：调節與控制」
   （PP p011）或「乙部 應用生態學」（PP p012），不含「卷二」二字。
3. **匹配矩阵取并集 = 灾难** —— 矩阵对个别题会落到卷一页（PP 的 p005 就是卷一），
   并进来后卷一的题号（1、2、3…）顶掉卷二的题号，整卷题号体系错位。
   **实测 FILL 从 11 题掉到 1 题**，而且错得很隐蔽（很多题变成「官方=[]」）。

最终规则（三条同时成立才用）：
- 参考 PDF 里**卷一卷二相连**，卷二＝尾端一段**连续页**；
- **anchor** = 首个带卷别标记的页（页面前 8 行有「卷二/試卷二/PAPER 2」，
  或页脚 `BIO 2-x`），卷二页 = anchor（前后各扩一页）到 PDF 末页；
- 匹配矩阵**只在该区间内**做补充，**绝不取并集**；
- anchor 找不到（2018／2020／SP）才整段改用匹配矩阵的页（该年份自身、
  score ≥ 0.12、不前后扩展），再取连续段。

顺带修好 PP 页脚的两种写法：`PP-DSE-BIO 2--5`（双连字符）、
`PP-DSE-BIO2--6`（无空格）—— 旧正则 `BIO\s*2\s*-\s*\d+` 两个都不匹配。

**这一轮再补 3 题**：2012 2(b) 5→8（官方 (b)(i)=3，与我先前手工数得分点的结果一致）、
2023 1(a) 7→10、2023 3(b) 7→9。

**累计（V0.25.3 + V0.25.4）**：补上 14 个空缺小题分值、修正 14 道大题 marksTotal。

**新版式仍是 0 题**：PP／2020／SP／2018 的右列是**裸数字**与 `2×2` 乘法式
（不是旧版的 `(1)`），解析器的 MARK/MARKX 正则没覆盖到；且这些年份的
小题标记行首排版与旧版不同。这是下一步的活。

## 补记（V0.25.5）：新版式打通 + 第二轮人工核对

### 新版式（PP／2020／SP／2018）为什么之前一题都抽不出来

新版式的评分参考有两个旧版没有的特点：

1. **题号与小题标记在同一个框里** —— 旧版是 `'1.'` 与 `'(a)(i)'` 两个独立框，
   新版是 `'1.(a) (i)'` 一个框。原来的题号正则要求整框只有题号
   （`^\d{1,2}[.．]$`），于是新版式一道题都识别不出来。
2. **右列是裸数字与 `2×2` 乘法式**，不是旧版的 `(1)`。

另外还踩了两个更隐蔽的坑：

3. **part 切换行被 OCR 读残** —— `'1. (b) (i)'` 会被读成 `'(b (i)'`（第一个右括号
   丢了）。原来的标记解析要求括号配对，于是**解析不出 part 切换，后一个大题的
   分值被并进前一个大题**（2017 1(a) 因此被算成 19 分，官方其实只有 11 分）。
   解法：解析标记时**不要求右括号**，靠 `findall(r"[（(]\s*([a-z]{1,3}|\d{1,2})")`
   取前三个 token。
4. **题号必须连续** —— 正文里的「10.」「11.」会被当题号。规则：
   候选题号要么是已知题号、要么正好是当前题号 +1、要么**更小**（更小 = 前面
   的题号是误判，重置）。2013 的 p006 还留着**卷一第 10 题的尾巴**，就是靠
   「回退即重置」这条救回来的。

### 第二轮人工核对（逐页看图）

### 2014 第 3 题的修正

| 题 | 原状 | 修正后 | 依据 |
|---|---|---|---|
| 3(a) | 一条 subq 塞了 (i)(ii)(iii)(iv)(1)(2) 六个小题，总分记 3 | 6 条 subq，总分 **12** | 原卷印刷：(i)3+(ii)3+(iii)2+(iv)(1)1+(iv)(2)3 |
| 3(b) | (i) 被併进 stem；(ii) 这个**引導句**被误记 3 分 | (i)3 + (ii) 引导句无分 + (1)2 + (2)3，总分 **8** | 原卷印刷 |

原卷截图还提供了 3(b) 的**流程图内容**，一举解决了题解稿里那个悬案：

```
收集新鮮牛奶 → (I) 巴斯德消毒法 → (II) 發酵／凝固：加入某種細菌，並可加入黴菌孢子 → (III) 成熟
```

此前题解稿写的是「(I)、(II) 的具體內容須對照原卷流程圖判讀，以下為一般流程的對應」——
现在可以确定了，题解稿已改写。

### 一个把「缺口」数字纠正过来的发现

之前一直说「还有 70 多个子题缺分值」。用 level 区分后才发现**其中 69 个是 level=1 的
引導句**（本身就不该有独立分值），**真正的缺口只有 3 个**（level=2）：

- 2018 3(a)(2)、2022 2(a)(2)、PP 3(b)(2)

并且 **106/106 题的「子题分值和 == marksTotal」全部成立** —— 这从内部一致性上
证明了那 69 条确实是引導句，不是漏记。**以后报缺口数必须区分 level。**

### 建模惯例（从原卷确认）

原卷上**引導句不印分值**，分值印在它下面的具体小题旁。所以：

- level=1 且 `marks=None` → 引導句（正常）
- level=2 且 `marks=None` → 真缺口

`lq_ref_manual.py` 已扩展支持 `newSubs`（整份替换 subqs）、`stem`、`reviewed` 三个新字段，
人工核对结论仍集中在这一处、可重放。

### 原卷 PDF 文本层的可用性（别再指望它）

| 年份 | 原卷 PDF 文本层 |
|---|---|
| 2013 / 2015 / 2017 / SP | 部分页可用（4–6 页） |
| 其余 10 份 | **全是扫描件**，逐字文本层或只有水印文字 |

所以「从原卷 PDF 直接抽印刷分值」只能走**页图 + RapidOCR**（我们有全部年份的原卷页图
`scratch/_lq_pages/`），不能靠 PDF 文本层。

## 补记（V0.25.7）：原卷印刷分值 —— 第三个权威来源，推翻了前两轮的结论

### 为什么要有第三个来源

前面两轮都用了《評卷參考》：

1. **PaddleOCR-VL** —— 读不出评分参考最右侧那列孤立小数字（整列被吞进正文块），全量要 11 小时。
2. **RapidOCR + 连通域** —— 可行，但只给「得分点」，**小题分值要靠反推**，会漏读。

而**原卷上每道小题右边直接印着分值**（如 `(3 分)`），这是最权威、最直接的来源 ——
考生在考场看到的就是这个数。之前一直没做，是因为以为原卷 PDF 的文本层能直接读。

### 原卷 PDF 文本层不可用（别再指望）

| 年份 | 原卷 PDF 文本层 |
|---|---|
| 2013 / 2015 / 2017 / SP | 部分页可用（4–6 页） |
| 其余 10 份 | **全是扫描件**，逐字文本层或只有水印文字 |

所以只能走**页图 + RapidOCR**（`scratch/_lq_pages/` 有全部年份的原卷页图）。

### 一个被证伪的结论（最重要）

上一轮我写过：「72 条无分值条目里 69 条是 level=1 的引导句，**真缺口只有 3 个**」，
并用「106/106 题子题分值和 == marksTotal」佐证。

**这个结论是错的。**「子题分值和 == marksTotal」只能证明**内部自洽**，
因为两个数都来自同一批漏读的资料。用原卷印刷分值一验就现形：

| 题 | 我们记 | 原卷印刷 | 差 |
|---|---|---|---|
| **2014 1(a)** | 5 分（(i) 记 None） | **(i)4 + (1)3 + (2)2 = 9 分** | −4 |
| **2014 1(b)** | 6 分（(iv) 记 None） | **(i)1+(ii)2+(iii)3+(iv)5 = 11 分** | −5 |
| **2018 3(a)** | 7 分（(2) 记 None） | (i)2+(1)2+(2)4+(3)3 = **11 分** | −4 |
| **2022 2(a)** | 9 分 | (1)1+(2)1+(3)3+(1)2+(I)2+**(II)2** = **11 分** | −2 |
| **PP 3(b)** | 9 分 | 2+2+2+1+**(1)2**+2 = **11 分** | −2 |

**2014 1(a) 的 (i) 和 1(b) 的 (iv) 都是 level=1**，所以「level=1 且无分值 = 引导句」
这个推断也是错的 —— 真正的引导句是原卷上**不印分值**的那些行。
→ **以后判断引导句只能看原卷，不能看 level。**

### 顺带修正了一处题解的方向性错误

**2022 2(a)(2)(i)**：官方《評卷參考》的得分点是
「**分解作用是需氧過程 → 分解速率降低 → 草原土壤含銨量較初級雨林低**」，
而我们题解写的是「硝化作用受抑制 → 氨含量**較高**」—— **方向反了**。
已按官方答案改写，并补上 (2)(ii)「硝化降低／反硝化增加 → 無機氮含量較低」的题解。

这也是「拿官方得分点表述对照题解」这条待办的第一次实战收获 ——
自动比对噪声大，但**逐页看图**一次就抓到一个方向性错误。

### 两个新工具

- `lq_orig_marks.py` —— 对原卷页图做 OCR，能 dump 任意一页的「分值 + 小题标记」：
  ```
  python scripts/pastpaper/lq_orig_marks.py find 2018 益生菌
  python scripts/pastpaper/lq_orig_marks.py dump 2018 p005
  ```
- `lq_orig_verify.py` —— 全卷原卷印刷分值总量校对。**只做总量、不做小题级**：
  原卷的题号行经常被 OCR 漏读（2014 p004 的「2(b)」整个没认出来），
  小题级自动对齐不可靠；但「(N 分)」这种括号格式正文里不会出现，
  只可能是印刷分值，所以**全卷加总**的信噪比最高。

实测：2012 与 SP 的原卷印刷分值与我们**完全吻合**（分值和、标记数都一致）；
2014 脚本少抓 9 分，逐一查过 —— 全是 RapidOCR 漏读数字（「(1 分)」读成「分）」）
和「分值单独成行且下一行内容多」的版式特例。

### 还剩什么

自动提取只能当**筛查工具**（差异大的年份重点人工看），
逐份卷对着原卷图人工核对才能定案 —— 14 份卷 × 8 题 = 112 题，工作量不小。
