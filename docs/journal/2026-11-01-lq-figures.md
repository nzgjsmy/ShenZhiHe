# 2026-11-01 · 卷二 LQ 原卷页图上线

作者：WorkBuddy

## 起因

用户：「生物长题目目前还没有题目的图像」。核对属实 —— `_lq.json` 里 110 道大题的 `imgs` **全部是空数组**，
前端 `lqCard()` 只能显示一句「配圖裁切中，暫請對照原卷」。

卷二很多题必须看图才能作答（曲线图、DNA 指纹、流程圖、顯微照片），
没有图等于这些题根本做不了。

## 决策：整页原卷图，不做自动裁单图

先试了「自动裁出单个图」：用墨迹闭运算找连通块，再用「长直线数 + 墨迹密度」区分图与文字段落。

实测失败：

| 页 | 实际内容 | 判据结论 |
|---|---|---|
| 2019 p001 | 圖 1 曲线图 | FIG（正确） |
| 2019 p002 | 圖 2 曲线图 | **text?**（vl=0，曲线图没有长直线） |
| 2019 p003 | 一大段文字 + 表格 | **FIG**（表格有 14 条竖线，被误判成图） |

**裁错比没有图更糟** —— 学生会看着错的图作答。所以放弃自动裁单图。

改成 **整页原卷图**：只裁掉页面四周空白，内容一字不动。学生看到的就是原卷版面，
和真考试一致。代价是页面里也包含相邻题的文字，但不会误导。

## 实现

新增 `scripts/pastpaper/lq_figures.py`：

1. 按题号算页范围（`page` 到下一题 `page - 1`，最后一题吃到末页）
2. 每页：二值化 → 去噪 → 算墨迹包围盒 → 裁 → 缩到 1000px 宽 → webp q78
3. 写回 `_lq.json` 的 `imgs` 字段

结果：**108 题有图 · 120 张 · 9.5 MB**（2014 丁部 2 题无图，原卷扫描件本身缺那几页）。

## 三个踩到的坑

### 1. 页范围必须按**题号顺序**算，不能按数组顺序

2018 的 `1(b)` 是后来补录的（V0.25.8 拆出来的），**追加在数组末尾**，但 `page=2`。

第一版按数组顺序 + 单调性修正，把 `1(b)` 的 page 从 2 改成 9 →
**配到第 9 页**（4(b) 的内容）。而且 `1(a)` 被算成跨 8 页。

改成 `sorted(qs, key=qkey)` 按 `(题号, 小问字母)` 排序后再算范围，`page` 字段本身一个字不改。

**教训：数据数组的顺序不等于逻辑顺序。** 后补的题一定追加在末尾。

### 2. 扫描站水印撑大包围盒

原卷页右下角有 `Provided by dse.life` 水印，在 y≈2149（页高 2200）。
包围盒算到它，图下面多留 40% 空白（2019 p001 裁出 1362px，实际内容只有 1047px）。

修法：找所有「墨迹行段」，从后往前跳过高度 < 12px 的段（那是扫描噪点/页边黑线），
若最后一个真段的起点在页底 14% 内、且与上一段间隔 > 40px → 当水印删掉。

⚠️ 第一次写错：直接取「最后一段」，结果取到 y=2189-2194 那条 6px 噪点，水印没删掉。
**必须先过滤噪点段。**

### 3. 前端折叠必须用 `grid-template-rows`，不能用 `hidden`

照 §4.12 的规矩：`.lq-figbox{grid-template-rows:0fr}` → `.open{1fr}`。
110 题每题都放一张整页图，不收起会让 LQ 页长到没法读。

收起时实测高度 **0px**（`0fr` + `overflow:hidden` 生效）。

## 前端改动

| 位置 | 改动 |
|---|---|
| `lqCard()` | `imgs` 非空 → 渲染「📄 對照原卷 · 第 N 頁」折叠条；`imgMissing` → 显示缺失提示 |
| 新增 `lqToggleFig()` | 展开时把首图的 `loading` 从 `lazy` 改成 `eager`（0fr 容器里的图不会自动载入） |
| 新增 `lqZoom()` | 点图全屏查看。**手机上原卷缩到 286px 根本看不清坐标轴**，必须能放大 |
| `prep_ghpages.py` | 加 `img/lq/(年份\|PP\|SP)/p\d{3}.webp` 正则 —— 不加会整批 404（V0.20.0 踩过一模一样的坑） |

放大层：桌面端 `max-height:calc(100vh - 20px)` 完整显示；手机端 `width:100%` + 容器可滚动，
字号比内嵌时大 3 倍，坐标轴数字能看清。

  `lq_figures.py`**，只能直接用已入库的 `site/img/lq/`。要重跑得先自己重新生成页图。
- 2014 丁部（4(a)、4(b)）原卷扫描件缺页，永远不会有中文原卷图。前端已如实标注。
- 部署体积：`gh-pages/img/` 从 1182 张 / 50MB → 增加 9.5MB。
