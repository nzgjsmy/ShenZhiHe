## 關鍵判斷（SP 三題被推翻）

SP 是樣本卷，只有試題、沒有評卷參考，36 題全部自解。逐題二次核對時推翻了先前三題：

### Q21 電極極性（B → D）

放大 `f21` 後仍看不清，最後用 **像素投影量座標** 定案：

- 頂部橫線在 y≈16；`x=280–281` 的細長豎線跨越橫線上下（長線＝**正極**）；`x=287–293` 的短粗黑塊（短線＝**負極**）。
- 左導線 `x=236` 接長線那側 → **正極**；右導線 `x=330` 接短粗線那側 → 負極。
- 左電極標籤「碳電極 Y」在 `x=7–100`、「碳電極 X」在 `x=412–504` → **左邊是 Y**。

結論：**Y 接正極＝陽極**。故 Cr₂O₇²⁻ 陰離子移向 Y，Y 側確實漸呈橙色，(1)(2)(3) 全部正確 → **D**。

> 教訓：座標一定要用投影量，肉眼在 2× 放大圖上判斷左右極性會出錯；而且「左邊是 X」這種默認假設必須回頭核對標籤位置。

### Q4 聚合物單體（1,2-二甲基乙烯 → 1,1-二甲基乙烯）

把 `f04` 再放大到 2× 逐碳看：主鏈碳交替為 **H/H（–CH₂–）** 與 **CH₃/CH₃（–C(CH₃)₂–）**，重複單元 –CH₂–C(CH₃)₂–，單體 CH₂=C(CH₃)₂。

選項 A「1,1-二甲基乙烯」與選項 C「甲基丙烯」其實指同一化合物；取 A 的理由是 C 未標位置（甲基可落在丙烯三個位置，分別對應丁-2-烯／異丁烯／丁-1-烯），不能唯一確定結構。

### Q35 敘述句對（A → B）

「工業程序中多使用催化劑」＋「催化不影響生成物在平衡混合物中所佔的百分比」：兩句都對，但第二句說的是「不改變產率」這一性質，**不是**工業採用催化劑的理由（理由是加快速率、縮短達平衡時間、省能耗），故第二句非合理解釋 → **B**。
