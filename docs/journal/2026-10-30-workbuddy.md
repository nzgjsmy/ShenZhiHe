## 验证 VLM 是否真的解决问题

跑 `lq_vl_parse.py` 三年：

| 年份 | 结果 |
|---|---|
| 2019 | 8 道大题，编号 `1(a) 1(b) 2(a) 2(b) 3(a) 3(b) 4(a) 4(b)`，**推断数 0** |
| 2020 | 7 道（缺 4(b)） |
| 2021 | 8 道，推断数 0 |

对比 PP-OCR 版：2019 切出 **9 个错误分组、全部需推断**。
VLM 彻底解决了「小题当大题」的问题 —— 因为它给的是**完整语义单元**，题号在行首，
不需要靠 x 坐标猜层级。

### 2020 缺 4(b) 的真相

不是丢页。`p011.json` 里 4(b) 的内容完整在（唐氏综合症、胎儿游离 DNA 那题），
**只是题号「4(b)」本身被 VLM 漏读了**。所以 p11 的块直接以题干正文开头。

→ 结论：VLM 也会漏题号，但只漏个别，不是整年。这类可由人工补号解决。

## 做了什么

### 1. 重启 VLM 后台跑剩余年份

顺序刻意安排：**2018（已有 1 页）→ 2022/2023（近年）→ 2012-2017（历史）→ SP → PP（30 页最费时）**。
这样即使中途中断，也是高价值年份先完成。

```bash
python scripts/pastpaper/lq_vl.py 2018 2022 2023 2012 2013 2014 2015 2016 2017 SP PP
```

约 4 分钟/页 × 110 页 ≈ 5.5 小时。已确认可中断续跑（`run_page` 见已存在文件就 skip）。

### 2. 建立 `_lq.json` 数据文件

`lq_dataset.py`：VL 解析产物 → 正式数据。设计与 MC 完全平行但**文件独立**：

```
data/bio/_pastpaper.json  ← 卷一 MC（446 题，一字未动）
data/bio/_lq.json         ← 卷二 LQ（新，独立 schema）
```

单题结构：
```json
{
  "id": "lq_2019_q1a", "year": "2019", "qnum": "1(a)",
  "part": "A", "partName": "甲部", "chapter": "人體生理學：調節與控制",
  "stem": "為探究雌激素與促卵泡激素（FSH）之間的相互關係…",
  "subqs": [ {"no":"i","level":1,"q":"…","marks":null},
             {"no":"1","level":2,"q":"…","marks":2} ],
  "marksTotal": 10, "page": 1, "ocr": true, "needsReview": true
}
```

**层级由编号形态决定**：罗马数字 `(i)` = level 1，阿拉伯数字 `(1)` = level 2。

### 3. 分值兜底（踩了一个坑）

第一次跑出来 2019 只有 62 分、2020 有题「分值 None」。

原因：VLM 的 `marks` 是**按出现顺序的扁平数组**，个别分值会被吞掉。
实测 2020 2(a)：只有 `(i)` `(iii)` 两个子题，但 `marks=[2,4,3]` 三个值 —— `(ii)` 整条丢失。

兜底策略：把 marks 里没被用掉的值按顺序补给「无分值」子题，优先补 level 2，再补 level 1；
凡补过的标 `marksInferred`，整题标 `needsReview`。

修完：2019 **74 分**、2020 **74 分**、2021 **78 分** —— 接近 DSE 生物卷二真实满分（约 75–80）。

> 第一次兜底没生效：只补 `level==2`，而 2020 2(a) 的 `(i)(iii)` 都是 level 1。
> 加上「补完 level 2 还有剩就补 level 1」才修好。
