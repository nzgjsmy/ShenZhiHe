## 2C 微觀世界 II（13 章 54 点）

章节：八隅體規則與三類例外 → 電子圖與三種鍵 → VSEPR 四步 → 七種基本形狀＋總表 → 含重鍵分子 → 電負性與極性鍵 → 分子極性三步 → 靜電偏轉 → 範德華力 → 偶極－偶極 → 氫鍵 → 沸點比較 → 氫鍵對水與醇

几个刻意的取舍：

- **形状总表列满 12 行**（键合对／孤对 → 形状），因为练习里 XeF₂、ClF₃、XeF₄、SF₄ 都出现过，只列七种基本形状不够。
- **SO₂ 与 H₂O 都写 V 形，但注明成因不同**：SO₂ 是 3 个电子域、键角约 119°；H₂O 是 4 域、104.5°。这是学生最容易混的一组。
- 氢键一节做了「能／不能形成」对照表，并解释 **HCl 为甚么不算氢键**（Cl 电负性不足、半径大），因为 DSE 的判定门槛就是「H 连 F／O／N」。
- 从 `17 氫鍵_sol.pdf` 抽出 DSE 12／18／22／23 挂成 `exam`（必考熱點），评分用语写进 keywords。

## 5 化學世界中的規律（11 章 31 点）

章节：週期表發展 → 元素類別 → 結構與鍵合變化 → 電負性趨勢 → 熔點 → 導電性 → 氧化物化學式 → 酸鹼性 → 水對氧化物 → 過渡金屬 → 比較題框架

- 熔点、导电性两节都写成「**先讲结构、再讲要克服甚么力**」，因为 BK5 的标准答案就是这个两层结构。
- SiO₂ 为甚么算酸性氧化物，特别点出「判断标准是能否中和碱，**不是**能否溶于水」——这是 BK5 第 (ii) 问的原意。
- P₄O₁₀ 与 P₂O₅（实验式）分开写，避免「问实验式答分子式」。
- 过渡金属只保留 DSE 会问的三项通性，并补上 Zn²⁺／Sc³⁺ 无色的例外。
