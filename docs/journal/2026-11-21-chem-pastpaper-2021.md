## 二、逐題核對要點

答案串（Q1→Q36）：`D B C D B C D A A C A D A A D B C A C B C D A B D B C A C D A B A D C B`

四題必須回原卷放大看：

1. **Q2（電解池）**：電源符號左邊是短粗線（負極）、右邊是長線（正極），所以 X 是陰極、Y 是陽極。陽極放 O₂，答案 B「在 Y 周圍觀察到氣泡」。凝膠中 Cu²⁺ 遷向陰極（藍）、Cr₂O₇²⁻ 遷向陽極（橙），A/C 把顏色講反；外電路電子由 Y 流出，D 錯。**這題是第一眼容易誤判極性的一題。**
2. **Q7（氧化數）**：Pb₁₀(VO₄)₆F₂，必須先展開 VO₄ 中的 4 個氧：10(+2) + 6[x + 4(−2)] + 2(−1) = 0 → x = +5。只算 V + 4O 而不乘 6 會得到 −3 這個干擾項。
3. **Q17（命名）**：CH₂BrCHBrCH₂CH₂I。從碘端編號得 1,3,4；從溴端得 1,2,4。位次集較低者為 1,2,4，故為 1,2-二溴-4-碘丁烷（取代基按英文字母序，bromo 先於 iodo）。
4. **Q19（第 VI 族）**：M = 52.1 → Cr，第四周期過渡金屬。但 DSE 課程的「第 VI 族」指氧族（第 16 族），Cr 屬第 6 族（VIB），故 (2) 錯，答案 C。

其餘需留意的：Q5（Ba²⁺ 過量、NO₃⁻ 6.0 mmol 最多）、Q15（7.89 g CO → ΔHc −284 → ΔHf(CO) −110）、Q20（PET：圖 (1) 缺 —CH₂CH₂— 不是重複單位，(3) HOCH₂COOH 不是單體）、Q31（Q = 2.0 < Kc = 4.0，正向進行）、Q35（C=O 與 N 隔一個碳，不是酰胺，但含酮基可還原成醇）。
