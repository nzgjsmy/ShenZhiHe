可以弄个二层结构，用户一开始会在卷一 MC 的右边看到长题目，点进去之后会看到卷一长题目和卷二长题目」。

## 现状核对

- 卷二 LQ 已有 110 道（14 年，含参考答案）
- **卷一乙部此前完全没收**：`scratch/_pp_pages/<年份>/` 里其实早就有整份卷一的页图
  （24–35 页），但只用甲部 MC 的配图，乙部一直没动
- 卷一乙部结构：`1.` … `11.` 大題（阿拉伯数字＋句点），小題 `(a)(b)`，再下 `(i)(ii)`
- 每年 10–11 道，13 份卷合计约 130 道（2023 无页图）

## 做法

### 1. 识别：复用卷二那套 PaddleOCR-VL

`lq_vl_par.py` 本来就支持 `LQ_PAGES_DIR` / `LQ_OUT_DIR` 环境变量，直接指过去即可：

```bash
LQ_PAGES_DIR=scratch/_pp_pages LQ_OUT_DIR=scratch/_p1_vl \
  python scripts/pastpaper/lq_vl_par.py --workers 4 --first-page 14 2019
```

`--first-page` 用来跳过甲部 MC 页（乙部起始页逐年不同，先按「甲部完」检测）。

实测速度：**约 250–370 秒/页**，4 workers 并行度不高（CPU 抢核），
17 页跑了约 55 分钟。全量 200 页估 5–6 小时，只能挂后台。

### 2. 解析：新写 `lq1_parse.py`

**不能直接套 `lq_parse.py`**：卷二的大题题号自带小问（`1(a)`），一年 4 道；
卷一乙部是纯数字 `1.`、一年 10–11 道，小问另起。两者切分逻辑完全不同。

三个必须处理的坑：

| 坑 | 现象 | 解法 |
|---|---|---|
| 题号与小问同块 | `1. (a) 物理屏障和化學屏障…` 是一整块，只取 group(2) 当题干 → **整题少一个小题** | 匹配到题号后，对剩余内容再跑一次 `(a)` 判定 |
| 大题题号整块丢失 | 2019 的 `8.` 完全没被读到，p23 直接从 `(a) 蝙蝠是夜間出沒的動物…` 开始 → 整题被并进 Q7 | **同一大题不会出现两个 (a)** —— 再遇到 (a) 就推断新大题，题号 = 上一题 +1 |
| 图内标注 / 答题簿提示混入题干 | 「顯微照片X」「着絲點」「請在此貼上電腦條碼」「將不予評閱」 | `DROP_LABELS` 加 `figure_title`/`vision_footnote`；`NOISE` 正则剔除印刷提示 |

### 3. 原卷页图：`lq_figures.py` 改成一套服务两卷

加三个环境变量（`LQ_JSON` / `LQ_PAGES_DIR` / `LQ_IMG_REL`），默认值仍是卷二，
卷一乙部这样调：

```bash
LQ_JSON=data/bio/_lq_p1.json LQ_PAGES_DIR=scratch/_pp_pages LQ_IMG_REL=img/lq1 \
  python scripts/pastpaper/lq_figures.py 2019
```

`prep_ghpages.py` 的正则同步扩成 `img/lq1?/` —— 不扩的话卷一页图线上会整批 404
（V0.20.0 和 V0.25.13 都栽在这上面）。

### 4. 前端：二层结构

```
真題頁：[🏷️ 按話題] [📅 按年份] [📖 長題目]      ← 新增第三个
                                    ↓
長題目頁：[📄 卷一 · 乙部 11] [📚 卷二 · 甲–丁部 110]   ← 二层
         年份 chips → 按年份分组的 lqCard（复用卷二那套）
```

几个细节：

- `LQ_PAPER` 全局状态（1=卷一，2=卷二），`lqAll(p)` / `lqYearList(p)` / `lqPartName(p,paper)` 都带 paper 参数
- **切卷时年份与分部筛选一律重置** —— 两卷年份范围和分部都不一样，沿用旧筛选会出空画面
- 分部 chips 改成「从资料实际有的取」，不写死 A–D：卷一乙部只有 B，写死会多出三个空 chip
- 资料分开存（`_lq_p1.json` vs `_lq.json`）：题号体系不同（卷一 1–11、卷二 1–4 分甲乙丙丁），
  混在一起「N 道大题」这个数字会失真

### 必修一：甲部 MC 混进乙部（11 道）

2014 的 q34／q35／q36（p11，选项是 `A. 1 和 2 B. 1 和 3`）其实是**卷一甲部最后三道选择题**，
被当成乙部大题收进来了。2015 三道、2016 两道、2017 三道，共 11 道。

根因：`lq1_parse.py` 有 `--first` 参数（跳过甲部），但之前跑批没传，等于从第 1 页开始解析。

修法：**不依赖人工传参**，在 parse 收尾加「题号回落」检测 —— 甲部 q1→q36 连续，
乙部再从 1 重新编号，那个 `36 → 1` 的断点就是乙部起点。

效果：2014/2015/2016/2017 各从 14/14/13/14 道回到 **11 道**，与 DSE 实际一致（乙部每年 11 题）。

### 必修二：2013 页图错位，源 PDF 就重复

判断依据是页脚：PDF 每页底部印着 `2013-DSE-BIO 1B-N`，与文件名 `pNNN.jpg` 应单调对应。
实测（读 `_pp_pages/2013/ocr.json`）：

| 文件 | 页脚印的 | 应有 |
|---|---|---|
| p016 | 1B-3 | 1B-6 ❌ 与 p013 重复 |
| p023 | 1B-11 | 1B-13 ❌ 与 p021 重复 |
| p024 / p025 | 1B-14 / 1B-13 | 顺序颠倒 |

打开 `D:/生物DSE Past Paper/2013/2013 卷一.pdf` 第 16 页，文字层直接写着 `2013-DSE-BIO 1B一3`
—— **源 PDF 本身就重复了一页、丢了 1B-6**，不是提取脚本的锅。所以之前记的
「p021／p023 识别逾时」是误判，那两页一直都在，只是内容和别的页重复。

1B-6 上应该装着 q2 和 q6，1B-13 上是 q11 —— 这三题在现有源文件里补不回来。
当前处理：parse 加「同题号去重」（保留先出现的），2013 从 9 道（两道 q3）变成 **8 道**，
不再显示重复题，缺的 q2／q6／q11 如实空缺。

另新增 `scratch/_chk_pageorder.py`：按页脚批量体检每年页图顺序，一条命令看出哪年错位。

### 小改：空题干的指引

7 道题（2012 q4、2013 q9、2014 q7、2016 q6、2017 q5/q10、2019 q1/q8）题干是空的 ——
不是解析丢了，是原卷的题干直接印在图里（「對頁顯微照片…」）。空白会让人以为页面坏了，
`lqCard` 里补一句「本題題幹直接印在原卷圖上，請展開下方『對照原卷』查看」（`.lq-stem-empty`）。
