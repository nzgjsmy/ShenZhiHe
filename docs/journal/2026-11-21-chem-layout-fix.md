## 改了什么

### 1. 陈述编号分行（`site/template.html` 新增 `ppMarks()`）

```
(1) 它於焰色試驗中，得出金黃色火焰。
(2) 它於強熱時，放出一無色氣體。
(3) 它溶於稀硫酸得到一澄清的溶液。
```

规则要点：

- 只认 `(1)`–`(9)` 与**小写** `(i)(ii)(iii)(iv)`，且编号后必须接空白或中文。
- 化学式里的氧化态是**大写**（`氯化鈷(II)`），天然不受影响——这是必须守住的边界。
- 表格 / 清单 / 标题 / 引用 / 图片 / 代码行整行跳过，避免把已有结构切碎。
- 全库 175 道题的题干命中。

### 2. 课题编号（`ppChTag()` 取代 `ppChNo()` 取数字）

旧写法：`/(\d+)/.exec(TMAP[k].pdf || k)` → 化学 id `1a/1b/1c` 全取到 `1`，于是三个都显示 `Ch01`。

新写法看 pdf 档名：

| 科目 | 档名样例 | 标签 |
|---|---|---|
| 化学 | `1A 化學筆記～～地球 Teacher.pdf` | `1A` |
| 化学 | `4B…TeacherVer.pdf`（用省略号接档名） | `4B` |
| 生物 | `Ch07 人體的氣體交換.pdf` | `Ch07` |

排序改为 `ppChNo` + `ppChTag` 字符串比较，得到 `1A < 1B < 1C < 2A < 2B < 3A < 3B < 3C < 4A < 4B < 6 < 8`。另把 1B 标题补回「微觀世界 I」。

## 顺带扫出 28 处「题解结论 ≠ 官方答案」

用 `→ X。` 结尾与 `answer` 字段比对，全库 28 处不一致（题库与各年答案表 100% 一致，所以错的是题解）。

三类：

- **题干/选项本身抄错（4 题）**
  - 2014 Q27：分子抄成 `CH₃CH=CHCH(CH₃)C₂H₅`，原卷是 `CH₃CH=CHCH₂CH(C₂H₅)₂`；后者两个乙基相同 → 不是手性中心 → 对映体 0（D）。
  - 2018 Q24：第一、第二述句顺序颠倒，导致「第一句错、第二句对」无从对应。
  - 2013 Q30：选项 B 原文是「結構異構體」，不是「對映異構體」——X/Y 恰恰是对映体，所以 B 错、D 对。
  - 2019 Q10：题干重复单元抄错，四个选项的**结构图整批缺失**，用户只能看到 A/B/C/D 四个字母。
- **推理方向反了（5 题）**：2018 Q21（锌碳电池用 NH₄Cl）、2019 Q15（化学电池阴极是正极，接上去加速腐蚀）、2016 Q28（醇不与 H₂ 加成）、2017 Q35（丁酸乙酯皂化给乙醇）、2018 Q6（NaOH 过量时 Zn(OH)₂ 溶解）。
- **记忆/数值错（6 题）**：2016 Q31（尼龙-66 是 (CH₂)₄）、2016 Q20（Pb²⁺ 仍占 6 层）、2013 Q22（浓硝酸放 NO₂ 可鉴别）、2017 Q25（熔点峰在 Si）、2020 Q27（A 是叔丁醇）、2020 Q32（丙氨酸两图同一分子）。

其余 13 题靠原卷图定案（2012 Q27、2014 Q29、2015 Q32、2016 Q12、2018 Q35、2019 Q25、2020 Q27/32 等）。
