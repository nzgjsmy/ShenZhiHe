# 年度諾貝爾獎置頂

> 2026-10-31 ｜ 三科總覽頁

## 需求

「我觉得在时事那边可以把三个诺贝尔奖给置顶，因为这些是科学贡献的最高成就。」

## 2026 年三個自然科學獎（以諾貝爾獎官網為準）

| 獎項 | 獲獎者 | 獲獎理由 | 對應科目 |
|---|---|---|---|
| 生理學或醫學獎 | Karl Deisseroth、Peter Hegemann、Georg Nagel | 光門控離子通道與光遺傳學的發現 | 生物 |
| 物理學獎 | Francis Halzen | 對冰立方微中子天文台（IceCube）的決定性貢獻，以及發現具天體物理起源的高能微中子 | 物理 |
| 化學獎 | Henri B. Kagan、Kenso Soai | 在不對稱有機合成中發現非線性效應與自催化現象 | 化學 |

三個獎剛好對應三個科目 —— 這不是巧合（我們只收自然科學三獎，本來就是衝著理組學生），
所以置頂在「科研時事」之上，學生一進來就看到今年最高的科學成就。

## 設計決定：為什麼不放進 `_news.json`

第一反應是給新聞條目加個 `pin: true` 就好。但想清楚後改成**獨立資料檔**：

1. **生命週期完全不同**。時事每天被 `fetch_news.py` 重寫（按日期排序、每科最多 3 條、
   只保留 9 條），而諾貝爾獎是**年度**的，要在版面上待一整年。
   放在同一個檔裡，就得在抓取腳本裡加一堆「這幾條不准動」的例外邏輯 —— 很容易被後來的改動弄丟。
2. **更新方式不同**。時事靠自動抓取，諾貝爾獎每年 10 月人類手動改一次。
   混在一起，維護的人容易搞不清哪些能改、哪些會被覆蓋。
3. **語義不同**。它是「年度榮譽」，不是「時事」。

所以新增 `data/_nobel.json`：

```json
{
  "year": 2026,
  "announced": "2026-10-05 ~ 10-07",
  "items": [ { "cat": "bio", "prize": "生理學或醫學獎", "who": "...", "t": "...", "x": "...", "url": "..." } ]
}
```

`build.py` 注入成 `DATA.nobel`，前端渲染在 `hn-news` **之前**。
每年 10 月公布後只改這一個檔（`year` + 三條 `items`），不必動程式。

## 視覺：要「明顯是最高榮譽」，但不能脫離手帳風

- 卡片沿用剪報的紙卡底（`--hn-paper`）+ 陰影，維持整體風格
- 但加**金色頂邊**（3px `--amber`）與極淡的金色描邊 —— 一眼區分於下面的時事卡
- 獎項名用金色膠囊標籤（`生理學或醫學獎`），科目標籤沿用時事那套配色
- 摘要下方一條點線分隔，列出獲獎者
- 全部用語義變數（`--amber` / `--amber-soft` / `--hn-paper` / `--text-soft`），
  深色模式自動跟著換 —— 實測深色下卡片 `rgb(34,37,43)`、字色 `rgb(184,179,168)`，無漏白

## 兩個踩到的小坑

### 1. 露出 markdown 星號

化學獎摘要裡我寫了「不對稱性可以被自催化**放大**」，想突顯機制關鍵詞。
但前端是 `esc()` 純文字渲染，結果畫面上直接顯示 `**放大**`。

修法：加一個 `hnMd()`，**先 `esc()` 擋注入、再把轉義後的 `**` 換成 `<b>`**。
順序不能反 —— 先替換再加 esc 會把 `<b>` 自己也轉義掉，而且先替換等於把未轉義的字串
拼進 HTML，是注入風險。

```js
function hnMd(s){ return esc(s).replace(/\*\*(.+?)\*\*/g,'<b>$1</b>'); }
```

### 2. 三張卡片底部不對齊

摘要長短不一（第一條短、後兩條長），來源連結就高低不齊。
改成 `.hn-nobel-item{display:flex;flex-direction:column}` + `.hn-nobel-x{flex:1}`，
把連結壓到卡底。實測三張連結的 `getBoundingClientRect().top` 都是 1383。

## 驗證

- 桌面 1200px：3 張卡片、在科研時事之上、無 JS 錯誤
- 深色模式：卡片底色深、字清晰、金色頂邊更醒目、無漏白
- 手機 390px：單欄堆疊、三張寬度都是 362px、無橫向溢出

## 以後每年怎麼更新

10 月獎項公布後：
1. 改 `data/_nobel.json` 的 `year`、`announced`、三條 `items`
2. `python site/build.py` → 部署

不必碰 `build.py`、`template.html`、`fetch_news.py`。
