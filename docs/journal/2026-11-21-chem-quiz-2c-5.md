## 命题策略

每题都挂一个具体 `point`，干扰项做成「学生真的会犯的错」，而不是随机凑字。几个例子：

| 考点 | 干扰项怎么设 | 想逼出甚么 |
|---|---|---|
| CO₂ 直线但 SO₂ V 形 | 原子半径、键长、氧化数 | 真正原因是「S 上有孤对」 |
| CCl₄ 有极性键却非极性 | 「C—Cl 键本身没有极性」 | 最常见的误答 |
| XeF₂ 有 3 对孤对却非极性 | 另设一题 tf「有孤对就一定是极性分子」 | 「有孤对 = 极性」的迷思 |
| SiO₂ 不溶于水仍是酸性氧化物 | 同时出一道 tf「能溶于水就是酸性氧化物」 | 判断标准是「能否中和碱」 |
| P₄O₁₀ 的实验式 | 单独一题 tf 考 P₄O₁₀ → P₂O₅ | 实验式与分子式的区别 |
| CH₄ 沸点低于 CS₂ | 「C—H 键较弱」 | 沸点看分子间引力，不看键能 |
| 第二周期熔点 Ne < Li < Be < C | — | 对应 BK5 第 4 题，但换了情境 |
| Mg 熔点 > Na 熔点 | 「相对原子质量较大」 | 真正原因是离域电子数 |

另外刻意安排了几个「同一概念正面问 + 反面问」的配对（例如 CCl₄ 一题问「为甚么非极性」、一题把它放进「哪个是极性分子」的选项里），用来确认学生不是靠记选项位置答对。
