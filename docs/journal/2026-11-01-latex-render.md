# 2026-11-01 · 行內 LaTeX 渲染（修「$ 34^{\circ} $C」亂碼）

作者：WorkBuddy

## 起因

用户截图：卷二 LQ 题卡里 `在（a）描述的實驗，參與者在維持 $ 34^{\circ} $C 和 60-70% 相對濕度的室內進行運動。`

## 根因：站內根本沒有 LaTeX 渲染器

`inline()` 只处理 `**粗体**`、`` `代码` ``、`*斜体*`，然后交给 `subify()` 做下标。
`$...$` **一路原样输出**。不是这次改坏的，是从一开始就没实现。

全站扫了一遍，`$...$` 共 **87 处**，分布在 6 个文件：

| 文件 | 处数 | 内容 |
|---|---|---|
| `data/chem/4a.json` | 55 | 化学方程式、速率公式 |
| `data/bio/_lq.json` | 20 | 卷二题干里的温度、浓度、单位 |
| `data/chem/6.json` | 6 | 阿伦尼乌斯方程、原子经济 |
| `data/phys/energy2.json` | 4 | **其实是美元**（电费 $0.066） |
| `data/chem/8.json` | 1 | 比移值 Rf |
| `data/phys/elec3.json` | 1 | **其实是美元**（$1.1） |

## 决策：写轻量转换器，不引 KaTeX

KaTeX 要额外 300KB+ 字体，而本站是**离线 PWA**（字体得跟着打包）。为 87 个公式付这个代价不划算，
而且公式集很窄（上下标、希腊字母、`\ce`、`\frac`、`\times`、`\circ`）。

所以写了 `tex2html()` + `chemify()`，只覆盖实际用到的子集，**不认识的原样保留**（宁可少转，不要转坏）。

## 四个坑

### 1. `$` 有真假：LaTeX 定界符 vs 美元

物理电费题里 `電費 = $0.374` 是钱，不是公式。不加判断会被当成公式，把整段文字吞进 `tex2html`。

判据（`looksLikeTex`）：

- 内容含 `\` `^` `_` → 一定是公式
- 去掉空白后**以数字开头**（`$0.066`、`$ 12 W`）→ 当货币，原样保留
- 其余（`$t = 0$`、`$ Cb/Cp $`）→ 公式

### 2. `$$...$$` 必须排在 `$...$` 之前

化学笔记的块级公式写的是 `$$平均速率 = \frac{...}$$`。

单 `$` 的正则 `\$([^$\n]{1,200})\$` 匹配 `$$...$$` 时会从**第二个** `$` 开始，
把内容吃掉、留下首尾两个孤零零的 `$`。**7 条公式全中招。**

### 3. `\frac` 必须排在 `^{}` 之后

`\frac{體積}{24\ dm^3 mol^{-1}}` 的第二个参数里有 `^{-1}`，带花括号。
`\frac` 的参数正则 `[^{}]*` 会在 `^{-1}` 的 `{` 处断开 → **整条分式不转**。

正确顺序：先把 `^{}` `_{}` 变成 `<sup>`/`<sub>`（花括号消失），再处理 `\frac`。

### 4. `\ce{}` 里的 `>` 已被 esc 转义

`inline()` 是 `esc()` 之后才调 `tex2html`，所以 `->` 到手上已经是 `-&gt;`，
`/->/` 匹配不到，箭头全变成字面 `-&gt;`。`chemify()` 开头先还原。

另外 `+` **不要**做空格化：数据里 ` + ` 本来就有空格，强行加反而把电荷 `16H+(aq)` 拆成 `16H + (aq)`。

## 验证

七个页面遍历 DOM 文本节点，查残留 `$` 和 `\[a-zA-Z]`：

```
chem 4a        0 处
chem 6         0 处
chem 8         0 处
bio LQ         0 处
chem graph     0 处
phys energy2   3 处 ← 全是 $12 / $0.066 / $45.7（货币，正确保留）
phys elec3     3 处 ← 全是 $1.1 / $0.33 / $0.825（同上）
```

渲染效果（浅色 + 深色均截图确认）：

- `$ 34^{\circ} $C` → `34°C`
- `$ 5 \mu g L^{-1} $` → `5 μg L⁻¹`（`\mu` 后的空格被吃掉，符合 LaTeX 规则）
- `$\ce{CaCO3(s) + HNO3(aq)}$` → `CaCO₃(s) + HNO₃(aq)`
- `$\ce{2H2O2(aq) ->[催化剂][MnO2] 2H2O(l) + O2(g)}$` → 带箭头的完整方程式
- `$\dfrac{120\ cm^3}{60\ s}$` → 上下两行分式 + 分数线

`build + verify` 12 项全绿。
