# 2026-11-24 化学卷二：2018 入库 + 其余年份 MS 扫描汇总

## 2018

MS 21 页：卷一 p1–p8、**卷二 p9–p11（页眉「卷二」）**、p12 起考生表现（p17 也有「卷二」字样，是考生表现章的标题，别误判）。
页图 p2–p3（甲部）、p4–p5（乙部）、p6–p7（丙部）。

三题：
- **甲部**：膜电解池两条半反应式、M-B 曲线、维生素 C 原料（葡萄糖）；甲醇合成（Cu/ZnO/Al₂O₃、
  活化能高故缓慢、加压使平衡右移）、CO₂ 加氢制甲醇的绿色性与「消耗 CO₂」的好处、甲醇羰基化制乙酸；
  N₂O₅ 分解双温度 log–log 作图（斜率 = 级数 = 1、345 K 的 k = 0.01 s⁻¹、**Ea = 94.95 kJ mol⁻¹**）。
- **乙部**：乙烯基醋酸酯绿色合成、甲壳素与蟹壳、六方最密堆积图；螺旋（胆固醇型）液晶与 LCD 像素、
  高温液化；二甘醇 + 马来酸的聚酯、交联剂 A、热固性、靠 X/A 比例调刚性、模塑船身。
- **丙部**：Ca²⁺ 砖红焰色、酸化 Ba(NO₃)₂ 辨 SO₃²⁻/SO₄²⁻、Rf 定义；碘量法测 NaClO₃（**85.0%**）；
  X/Y 沸点太近不能分馏、IR 1700 是 C=O、m/z 43/55 → Y = 甲基乙烯基酮、X = 丁酮。

分值拆分修正：Q2 初版 22 分（(a)(ii) 与 (c)(ii)(1) 各多给 1 分），已改回 20。
