# V0.25.25.10 DSE 化学真题按新课题重新分类

日期：2026-11-22 00:40 ｜ 执行：WorkBuddy

## 起因

新增 2C、5 两个课题之后，575 道真题全部还挂在旧的 12 个课题上。1B「微觀世界 I」里塞了大量其实是分子形状、氢键、周期表的题——因为当初分类时这两个课题还不存在。

## 先定标准

这次把边界写清楚，以后加题也有据可依：

| 情况 | 归属 |
|---|---|
| 跨元素／跨周期比较（熔点、沸点、导电性、原子半径、电负性趋势） | **5** |
| 周期表位置、族、同族性质、过渡金属 | **5** |
| 氧化物酸碱性、两性、实验式与分子式 | **5** |
| 单个分子的形状（VSEPR）、极性键、分子极性 | **2C** |
| 八隅体规则与例外、电子图、配位键 | **2C** |
| 分子间引力、氢键、冰的开放结构、静电偏转 | **2C** |
| 原子结构、同位素、离子键／共价键／金属键、物质结构类型 | **1B** |

## 做法

不是关键词匹配就改，而是**读完 1B 全部 87 题**（连同 1C／2A／2B／6 的可疑题），逐题判断。最后换类 58 道，总数仍是 575。

## 几个值得记下来的判断

- **2016 Q16**（HF／HCl／PH₃／H₂Se 哪个沸点最高）→ 2C。考的是氢键，不是周期趋势。
- **2018 Q28**（氩与氪的沸点、硅与钠的熔点、钙与镁的熔点）→ 5。是跨元素的周期性比较。
- **2018 Q5**（石英比干冰硬）、**SP Q24**（CO₂ 与 SiO₂ 物理性质）→ 5；但单讲石英或白磷的题（2020 Q2、PP Q4、2017 Q30、2025 Q7）留在 1B。区别在「有没有跨元素比较」。
- **2019 Q24**（汞导电 + 离域电子）留在 1C，讲的是金属键。
- **2016 Q2**（硫化锂电子图）留在 1B，因为是离子化合物，不是 2C 的共价点叉法。
- **PP Q36**（H₂C=CF₂ 可否代表两个化合物）→ 3B，考的是顺反异构的判定条件，不是分子形状。
