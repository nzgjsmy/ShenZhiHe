# 落地页改三科总览 + 今日小知識（2026-10-30）

## 我连续猜错了两次

用户原话：「感觉可以把所谓的'首页'定在科目那边，就是每次用户刚打开神智核时，处在科目分页会好点」

我先看到「科目那边」，理解成**科目页**（`#/home`，比如「化學筆記」）。跑去验证，发现全新访客打开时**已经**落在科目页了，于是回复「这已经是当前行为」。

用户立刻纠正：「不是啦，我是想每次一加载完进入神智核时，我会访问三科分页那边」

这里的「科目」指的是**三科总览**（`#/subjects`，四张科目卡那一页），不是科目页。中文里「科目」「分页」「科目分页」「三科分页」几乎同形，靠上下文猜必错。

**教训：歧义词先确认再动手。** 这次多花了两轮往返，如果一开始就问「你说的'科目那边'是指四张卡的总览页，还是某一科的内页？」，一句就解决了。

顺带也说明另一件事：**用户描述「我想要 X」时，可能是「现在不是 X」**。我以为他在描述需求（其实已经在做），实际他在报告现象（打开落在了 A 但他想要 B）。

## 改了什么

### 1. 默认落点

```js
// 前
let h = location.hash || '#/home';
// 后
let h = location.hash || '#/subjects';
```

`route()` 里空 hash 就走三科总览。

**边界**：只影响「完全没有 hash」的情况（首次打开、根路径、清空地址栏）。带 hash 的链接（`#/bio/home`、`#/pastpaper`）行为不变 —— 分享出去的具体页面不会因为这次改动跑偏。

### 2. 顺带修的按钮 bug

三科页头部右侧按钮原本是：

```js
onclick="go('${SUB?'#/home':'#/subjects'}')"
文案：${SUB?'繼續 '+SUB.title:'開始學習'}
```

没有「当前科目」时，文案说「開始學習」，但目标是 `#/subjects` —— **就是当前页**。点了毫无反应，用户会以为坏了。

改成：

- 有当前科目 → 「繼續 化學 →」，跳 `#/home`
- 没有 → 不显示按钮，显示总量「4 科 · 1610 個知識點 · 2528 道題」

### 3. 今日小知識（占位通道）

用户说「在科目分页，我以后可能会加上每日科普小知识的部分」。既然还没内容，先把**通道**搭好，以后只填数据不改代码：

```
data/<科目>/_daily.json
{
  "items": [
    {"t": "标题", "x": "正文", "tag": "所属课题"}
  ]
}
```

- `build.py` 读到就注入 `SUB._daily`，读不到就是 `None`
- 前端：`_daily.length ? _daily[今天第几天 % 条数] : null`
- **没有内容 → 整块不渲染**，不留空壳、不占位

视觉上做成淡青纸条 + 左侧实边（`--accent-soft` + `--accent`），刻意和「今日任務」的黄色便利贴区分开 —— 两张都是便签会显得堆叠。

先放 bio 三条示例：

1. 為什麼抗生素對感冒沒用？
2. 高山上的植物為什麼葉子特別小？
3. 人體最長的細胞有多長？

内容都是无争议的生物学常识，且和 DSE 章节对应（`tag` 写了所属课题）。

## 验证

| 项目 | 结果 |
|---|---|
| 全新访客（清 localStorage）打开 | `subgrid: true`、4 张科目卡、导航高亮「科目」 |
| 落地页顶部右侧 | 「4 科 · 1610 個知識點 · 2528 道題」 |
| bio 科目页 | 出现「今日小知識」区块 |
| chem 科目页 | 不渲染（没有 `_daily.json`） |
| build | 通过，日志有 `note: bio 載入每日小知識 3 條` |
| `verify_build.py` | 13/13 |
| `guard_data.py` | 0 改动 |

## 遗留

- 只有 bio 有 `_daily.json`。chem / phys 进去看不到这一块 —— 要不要也加内容，等用户定。
- 「每日科普」目前是**按天数轮换**，不是真正「每天推送新内容」。如果要按日期精确对应（比如 12 月 1 日固定某一条），把 `items` 里加 `date` 字段再匹配即可，改动很小。
- 仍然没 bump 版本、没部署。
