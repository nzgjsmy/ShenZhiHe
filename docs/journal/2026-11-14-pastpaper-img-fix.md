## 起因

用户截图反馈 **PP 練習卷 Q23（進化·演化樹）** 选项区只有四个空白字母框，没有演化树。
题目本身是「按氨基酸差异数建树」的经典题，四个选项 A–D 全是树形图。

## 排查

1. 定位题目：`data/bio/_pastpaper.json` → `years.PP` → `qnum 23`（`pp_PP_q23`）。
   `options` 的 `v` 全是空字符串，靠 `optImg = img/pp/PP/o23.webp` 出图。
2. 打开 `o23.webp`（1187×236）——**内容是题干三行文字 + 表格**，四棵树被切在下面。
3. 回原卷 `D:/生物DSE Past Paper/pp/PP 卷一.pdf` → `scratch/_pp_pages/PP/p009.jpg`，
   OCR 定位「建構演化樹時」在 y≈620、「演化樹？」在 y≈957，四棵树在 y 1000–1460。

## 修法

```bash
python scripts/pastpaper/pp_recut.py --one PP 9 1000 1480 site/img/pp/PP/o23.webp
# → 1000×519，crop x388..1222 y1022..1455（tight 自动收到墨迹包络）
```

`pp_recut.py` 的 `tight()` 会按 `INK=178` 找墨迹行列并加 14px padding，
所以只要给一个「包含目标、不包含邻居」的粗略 y 范围就够。

## 两条配图铁律（写进记忆）

1. **`optImg` 只准截选项区**。把题干一起截进去，页面会「OCR 文字 + 图片文字」重复一遍，
   用户第一眼看到的就是重复表格，正是这次的现象。
2. **`img` 不准跨题**。一张图带进两三道题，等于让用户在 A 题看到 B、C 题的内容。
