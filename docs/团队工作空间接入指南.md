# 团队工作空间接入指南

> **一句话**：本地工作空间（你电脑上的文件夹）**不能**直接"接入"云端团队空间。
> 真正能共享的是**三层东西**：代码与规则（走 git）、资料与产物（走资料库团队空间）、协作容器（走项目）。
>
> 本文把三层拆开讲，并给出神智核（ShenZhiHe）的具体做法。

---

## 0. 先破除一个误解

WorkBuddy 里有三个容易混淆的「空间」：

| 名字 | 在哪 | 存什么 | 谁能看见 |
|---|---|---|---|
| **工作空间（本地）** | 你电脑上的文件夹 | 源码、数据、图片 | 只有本机 |
| **项目（Project）** | 云端 | 共享配置（指令/连接器/专家/技能）+ 项目资产库 + 任务 | 项目成员 |
| **资料库 → 团队空间** | 云端 | MD / CSV / HTML 文档树 | 按四档权限 |

本地工作空间**永远是本地的**。WorkBuddy 没有"把本地目录挂载成团队空间"的开关。
团队能看到的，是**你从本地推进云端的东西**——具体有三条路。

---

## 1. 三条接入路径（选你需要的）

### 路径 A：代码与规则 → 随 git 走 ✅ 已完成

这是最可靠、最不依赖套餐的路。**配置写在仓库里，队友 clone 即生效。**

神智核仓库已配好（`.codebuddy/`，随 `source` 分支分发）：

```
.codebuddy/
├─ CODEBUDDY.md              项目级记忆（自动加载）
├─ rules/team-workflow.md    团队通用规则（alwaysApply，每次自动加载）
├─ skills/shenzhihe-core/    构建/部署/数据守门技能
└─ commands/
   ├─ verify.md              /verify         一键构建+全量自检
   ├─ deploy.md              /deploy         一键部署六步+验收
   └─ write-explanation.md   /write-explanation  写题解（含守门检查）
```

**队友 clone 后自动获得：**

```bash
git clone https://github.com/nzgjsmy/ShenZhiHe.git
cd ShenZhiHe && git checkout source
```

- WorkBuddy / CodeBuddy 打开该目录 → 自动读 `AGENTS.md` + `.codebuddy/CODEBUDDY.md` + `rules/`
- 输入 `/` 就能看到 `/verify`、`/deploy`、`/write-explanation`
- 不用再口头交代"建站只能用 build.py""部署要先清后拷"——规则已经写死在文件里

> **验证方法**：让队友 clone 后，在 WorkBuddy 里问一句"神智核构建该用哪个脚本"，答得出 `build.py` 就说明配置生效了。

---

### 路径 B：资料与产物 → 上传到资料库团队空间

适用于**要给团队看的文档**，而不是代码。比如：题库导出、答案得分率图表、贡献指南、版本说明。

**操作步骤（客户端 UI，5 步）：**

1. 左侧边栏点**资料库**
2. 左栏找到**「团队空间」**区 → 点标题右侧 **+** 新建空间（一个项目/小组一个空间）
   - ⚠️ 找不到「团队空间」区？说明当前账号还没有团队，先让管理员把你加进团队
3. 空间内**上传本地文件**，或**让 Agent 直接生成到这里**（在任务里指定输出到该空间，产物即刻落进去）
4. 空间菜单 →**邀请和管理成员** → 复制链接 / 二维码邀请
5. 分配权限：

| 权限 | 能做什么 | 适合谁 |
|---|---|---|
| 查看 | 只看，不能改 | 汇报对象、外部过稿 |
| 编辑 | 新建、修改、整理 | 一起干活的队友 |
| 管理 | 管成员与权限 | 空间管理员 |
| 无权限 | 完全不能访问 | 未获授权者 |

链接可单独设为「需申请权限」——陌生人拿到链接也要你先批。

**容量**：体验版 5 GB / 标准版 10 GB / 高级版 20 GB / 旗舰版 50 GB。

> ⚠️ **本项目不适合整包上传**：`site/` 513 MB + `gh-pages/` 52 MB 远超配额。
> 只上传精选产物（单个 MD / CSV / HTML / PDF），代码仍走 git。

**工具提示**：Agent 有 `LibraryUpload` 能力，可以把单个本地文件（≤100 MiB）存入资料库。
但注意它**只能上传到你自己的资料库**，不能直接指定团队空间 id，也不生成分享链接——团队空间那步仍需在 UI 里做。

---

### 路径 C：协作容器 → 建「项目」

**项目**是 WorkBuddy 面向"团队一起干活"的容器，比团队空间多两块能力：

- **项目指令**：写给 AI 的全局行为规则，成员在项目里发起的任务**自动继承**
- **项目资产库**：成员上传的资料以 RAG 形式注入任务上下文

**操作步骤：**

1. 左侧导航栏点**项目** → 左上角 **+ 新建项目**
2. 填项目配置：

| 配置项 | 神智核建议填什么 |
|---|---|
| 名称 | 神智核 · DSE 笔记站 |
| 指令 | 把 `AGENTS.md` 的铁律压缩成 5–8 条核心规则（分支语义、构建入口、数据守门、部署先清后拷、版本 bump 粒度） |
| 连接器 | 需要就挂（如腾讯文档用于图表协作） |
| 技能 | 把 `.codebuddy/skills/shenzhihe-core` 的要点作为项目技能 |
| 专家 | 生物/化学学科方向的领域专家（可选） |

3. 项目详情页右上角**邀请** → 复制链接发给队友
4. 队友点链接 → 填备注 → 提交申请 → **管理员在消息中心审批**
5. 成员在项目里发任务时，项目指令 + 资产库 + 个人记忆**自动注入**，不用每次重述背景

**配额**（官方定价页）：体验版 5 个项目、单项目 3 人（限免 5 人）；标准版 10 个/5 人；高级版 15 个/8 人；旗舰版 20 个/10 人。

> **所以不必等付费**——体验版就能建项目、就能邀请 3–5 人试用。

**项目任务的三种协作模式**：

- **分享**：任务链接给他人，进入同一会话
- **流转**：把**产物 + 进度摘要 + 完整上下文**打包移交，接手方不用重新沟通背景
- **多人同场**：成员直接在项目里各自发起任务

## 2. 神智核推荐组合

| 承载物 | 走哪条路 | 理由 |
|---|---|---|
| 源码、题库数据、图片 | **git（路径 A）** | 已有 CI（source 分支每次 push 自动跑 build + verify），无需重复建设 |
| 硬约束、命令、记忆 | **`.codebuddy/`（路径 A）** | 已配置完成，clone 即生效 |
| 贡献指南、认领清单 | 路径 B 或直接留 git | 已是 git 里的 `docs/贡献指南.md`，不必重复上传 |
| 答案得分率图表、对外说明 | **路径 B（团队空间）** | 需要在线看和协作，且体积小 |
| 日常协作容器 | **路径 C（项目）** | 项目指令可让每个新成员自动继承铁律 |

**结论：神智核其实 80% 的"团队化"已经靠 git 完成了。**
真正还需要做的只有两件：① 建一个项目（路径 C）把指令和资产库挂上；② 需要在线协作的产物上传到团队空间（路径 B）。

## 3. 队友加入的标准流程

```bash
git clone https://github.com/nzgjsmy/ShenZhiHe.git
cd ShenZhiHe
git checkout source          # ★ 必须。main 只有部署产物
python site/build.py         # 首次构建
python scripts/verify_build.py   # 应全绿
```

然后在 WorkBuddy / CodeBuddy 里打开这个目录：

1. 规则**自动加载**（`AGENTS.md` + `.codebuddy/`）
2. 输入 `/` 使用 `/verify`、`/deploy`、`/write-explanation`
3. 需要在线协作的文档 → 找管理员在团队空间里开权限

**开工前必读**：`SHARED-MEMORY.md` §2 现状、§3 占用、§4 陷阱。

## 4. 常见疑问

**Q：本地改了文件，团队空间会自动更新吗？**
不会。团队空间是云端文档树，和本地文件系统是两份东西。要同步得手动上传，或用 `LibraryUpload`。**代码类内容一律走 git。**

**Q：Agent 会读到团队空间里我看不到的内容吗？**
不会。Agent 权限与当前用户完全一致——人看不到的，Agent 也读不到。无需单独给 Agent 配权限。

**Q：体验版够用吗？**
够起步：5 个项目、单项目 3 人（限免 5 人）、资料库 5 GB、每月 500 积分。
人更多、或需要细粒度权限/审计日志/组织级管控时再升级。

**Q：协作任务里我的个人连接器还能用吗？**
不能。**协作任务中个人授权连接器全部禁用**，只有公共授权连接器可用。开启协作前先确认项目配好了公共授权。

**Q：`.codebuddy/` 会被提交吗？**
会，这是有意的——它就是要随版本控制共享给团队。
`.codebuddy/settings.local.json`（个人本地配置）**不要提交**，会自动进 `.gitignore`。
