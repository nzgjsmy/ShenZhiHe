## 4. 三個關鍵機制（不知道就會踩）

### 4.1 `imgs` 是「對照原卷翻哪幾頁」，不是裝飾

站內長題卡片不內嵌大圖，而是給「📄 對照原卷 · 第 N 頁」的入口。`imgs` 掛錯題，學生點進去只看到純題目頁，就會以為「圖缺了」。

**教訓**：卷一乙部大量「對頁的顯微照片…」題型，當初切頁時圖頁被歸進**前一題**的取樣範圍。已修 4 組 8 題（2014 Q3/Q4、2015 Q4/Q5、2017 Q3/Q4、2018 Q2/Q3）。
**檢查方法**：抓 stem／subqs 含「對頁」的題，人工核對其 `imgs` 是否包含圖頁。

### 4.2 官方評分參考不可用，題解是自寫的

- `2012 MS.pdf` 有文字層但**中文字體編碼全亂**（整頁亂碼），只有 MC 答案表能讀；`2024 MS+CP.pdf` 是純掃描。
- 所以 142 題題解都按「題目 ＋ DSE 生物科評分慣例」整理，`guideSrc` 一律寫明「**非官方評分指引**」。
- 格式：開場一句點考點 → 逐小問「（x 分）」→ 評分點用 `-` 列 → 常見失分用 ⚠️。

### 4.3 三類 OCR／VLM 垃圾（每次加題必掃）

1. **整段被幻覺替換**：2014 Q7 的 `(b)(i)` 變成「根据项目进行补充说明…是否符合国家政策及相关法律法规要求」。
2. **藏文亂碼** `U+0F00–U+0FFF`：2015 Q4/Q8、2016 Q8/Q11、2018 Q4/Q8 都中過。
3. **小問被截斷／整題缺失**：2020 Q4 的 subqs 只剩 (iii)、總分記成 1（實際 7）；2020 Q11 整題被塞進 Q10 最後一小問尾部（還夾「欽定四庫全書 卷一…卷四十」）；2022 Q11 題幹夾「Date of Birth 2023-09-20」。

掃描片段（貼進 python 即可）：

```python
import json, io, re
d=json.load(io.open("data/bio/_lq_p1.json",encoding="utf-8"))
bad=[(y,q["qnum"]) for y in d["years"] for q in d["years"][y]
     for t in [(q.get("stem") or ""),(q.get("guide") or "")]+[(s.get("q") or "") for s in (q.get("subqs") or [])]
     if re.search(r"[\u0f00-\u0fff]", t) or "欽定四庫" in t or "Date of Birth" in t]
print(bad)
```

## 7. 新增一份「純掃描長題卷」的固定做法

以 PP 為例（31 頁 A4 掃描、無文字層、無 OCR 可用）：

1. `pymupdf` 逐頁看 `get_text()` 長度 → 找出乙部起訖頁（PP 是 p015–p031）。
2. 200 dpi 渲染 → PIL 縮到 1000 px 寬 → `img.save(..., "WEBP", quality=88, method=6)`，命名 `pNNN.webp`（= PDF 頁碼）。
3. **逐頁用視覺讀題**，抄出題幹、小問、分數、圖中標註；不確定就再裁圖放大看，別猜。
4. 建資料（`id` 用 `lq1_<year>_q<n>`），`page` 填 **PDF 頁碼**，`imgs` 填該題涉及的頁（含對頁圖）。
5. 寫題解，`guideSrc` 統一那句「本站依據…非官方評分指引」，`hasPoints=True`。
6. 小問編號用 `b(i)`／`b(i)(1)` 複合寫法，前端會顯示「（b(i)）」。
