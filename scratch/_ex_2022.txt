@@@Q 1 2022
**先讀懂圖中三種穿越方式**（原卷圖顯示 X、Y、Z 三種途徑）：

```
X：分子直接穿過磷脂雙分子層（簡單擴散）—— 圖中是直接穿越磷脂層的小分子
Y：經過蛋白質（載體／通道蛋白）協助 —— 圖中是一個跨膜蛋白，物質隨之通過
Z：經過另一種蛋白質通道 —— 圖中是多個三角形分子由通道蛋白通過
```

**判斷原則：物質的性質決定它走哪條路。**

| 物質 | 性質 | 穿越方式 |
|---|---|---|
| **氧氣** | 小、**非極性**、可溶於脂質 | **簡單擴散**（直接穿過磷脂雙層） |
| **葡萄糖** | 較大、**極性**、不溶於脂質 | **易化擴散**（需載體蛋白協助） |
| **水** | 小、極性但能少量穿過脂質層；需大量快速通過 | 經**水通道蛋白（aquaporin）** |

逐項核對選項（欄位 X ｜ Y ｜ Z）：

- **A 氧氣 ｜ 葡萄糖 ｜ 水 —— 正確**：
  - X 對應**簡單擴散**（非極性分子直接穿過磷脂雙層）→ 氧氣 ✓
  - Y 對應**載體蛋白協助**（較大的極性分子）→ 葡萄糖 ✓
  - Z 對應**通道蛋白** → 水 ✓
- **B 葡萄糖 ｜ 水 ｜ 氧氣**：把三者的途徑全錯配了。
- **C 水 ｜ 氧氣 ｜ 葡萄糖**：葡萄糖不該走簡單擴散。
- **D 水 ｜ 葡萄糖 ｜ 氧氣**：氧氣不該走通道蛋白途徑。

→ **A**。

**易錯點（高頻）**：
- 以為「水也走簡單擴散」——水確實能少量穿過磷脂層，但**大量快速通過要靠水通道蛋白**；這正是細胞膜的「差異透性」所在。
- 以為「葡萄糖靠簡單擴散」——葡萄糖是極性大分子，**必須有載體蛋白**，這也是糖尿病與「葡萄糖載體失效」相關的原理。

```
減數第一次分裂後期（後期 I）
        ↓
**同源染色體分離**，各自移向細胞的相反兩極
```

- **B**：上方兩條小染色體、下方兩條大染色體 → 這是「大小分離」，**同源染色體並沒有分離**（同源的兩條應該大小相同、一起移向一極）→ ✗
- **C**：圓形細胞內的赤道面排列，且大、小、大、小依次排列 → 這是**中期排列**（或後期 I 尚未分離的樣子），不是後期 → ✗

```
後期 I：同源染色體分離 → 兩極「看起來一樣」（各一大一小）
後期 II：姐妹染色單體分離 → 兩極看起來「大小不同」（因同源染色體已分開）
```

**易錯點**：把「後期 I」和「後期 II」搞混。判別關鍵是看**染色體是否成對同源**：
- 後期 I 時，同源染色體還是一對（大小相同），所以每極會拿到大小相同的一對中的一條 → 每極組成相同。

**關鍵：題幹說的是「無氧呼吸」**。

```
無氧呼吸（酵母，酒精發酵）
  ① 糖酵解（在**細胞質**）：葡萄糖 → 丙酮酸 ＋ ATP ＋ NADH
  ② 丙酮酸脫羧（在**細胞質**）：丙酮酸 → 乙醛 ＋ CO₂  ↑
  ③ 乙醛被還原：乙醛 + NADH → 乙醇 + NAD⁺
```

**所以 CO₂ 是在細胞質中，由丙酮酸脫羧產生。**

逐項檢查：

- **A 細胞質 —— 正確**。無氧呼吸全程在**細胞質**進行，CO₂ 由丙酮酸轉成乙醛時釋出 ✓
- B 細胞膜：不產生 CO₂ → ✗
- **C 線粒體基質**：這是**有氧呼吸**中克雷布斯循環釋放 CO₂ 的場所。但本題酵母處於**無氧環境**，根本不走克雷布斯循環 → ✗
- **D 線粒體內膜**：這是電子傳遞鏈的場所，與 CO₂ 產生無關 → ✗

→ **A**。

**有氧 vs 無氧，CO₂ 來自何處（對照表）**：

| | 有氧呼吸 | 無氧呼吸（乳酸型／酒精型） |
|---|---|---|
| 場所 | 細胞質 ＋ 線粒體 | **只有細胞質** |
| CO₂ 產生於 | **丙酮酸脫羧 ＋ 克雷布斯循環**（線粒體基質） | **丙酮酸脫羧**（細胞質） |
| 產物 | CO₂ ＋ 水 ＋ 大量 ATP | 乳酸或乙醇 ＋ 少量 ATP |

**易錯點**：看到「酵母」就以為是異養需氧生物 —— 酵母是**兼性厭氧**的，有氧時走有氧呼吸，缺氧時走酒精發酵。**本題題幹已明說「無氧呼吸」，就以無氧為準。**

**延伸**：表中數據顯示葡萄糖產 CO₂ 最多 → 說明酵母**分解葡萄糖的速率最快**（糖酵解是第一步，葡萄糖可直接進入糖酵解；而蔗糖、果糖需先水解/轉化）。

```
全身各處
   ↓（體循環回流）
上腔靜脈 / 下腔靜脈
   ↓
**右心房**   ← 紅血球到這裡
   ↓ 通過 **三尖瓣**（右房室瓣）
```

- **B 左心室**：到左心室要通過**二尖瓣**（左房室瓣），而且必須先經過肺部進行氣體交換 → ✗
- **C 右心房**：這是**通過瓣膜之前**的位置 → ✗
- **D 右心室 —— 正確**。紅血球經腔靜脈回到**右心房**，再通過**三尖瓣**進入**右心室** → ✓

**心臟四腔與瓣膜的完整對應（必背）**：

```
右心房 ──三尖瓣（右房室瓣）── 右心室 ──半月瓣（肺動脈瓣）── 肺動脈 → 肺

```

@@@Q 20 2022
**先想清楚左右心室的壓力**：

```
左心室：要把血泵到**全身** → 收縮壓力**高**（約 120 mmHg）
右心室：只要把血泵到**肺**   → 收縮壓力**低**（約 25 mmHg）
```

**有孔洞時，血液由高壓側流向低壓側** → 由**左心室流向右心室**。

然後追問：進入右心室後，血會去哪裡？**右心室 → 肺動脈 → 肺**。

所以完整路徑是：**左心室 → 右心室 → 肺動脈** → **B**。

逐項檢查：

- **A 左心室 → 右心室 → 主動脈**：錯在最後一段。主動脈接的是**左心室**，血一旦進入右心室，收縮時會被**泵入肺動脈**，不可能再流入主動脈 → ✗
- **B 左心室 → 右心室 → 肺動脈 —— 正確** ✓
- **C 右心室 → 左心室 → 主動脈**：方向相反。左心室壓力**高於**右心室，血液不會從低壓流向高壓 → ✗
- **D 右心室 → 左心室 → 肺動脈**：方向同樣相反，且肺動脈也不接左心室 → ✗

→ **B**。

**臨床延伸（這正是題目的背景）**：這種孔洞叫**室間隔缺損（VSD）**。患者會出現**左→右分流**，導致肺血流增加、肺動脈壓升高，嚴重時會发展为**艾森曼格氏症**（肺高壓導致反向分流，出現發紺）。若改成**右→左分流**（如 D 的方向），則會造成**發紺**（靜脈血混入體循環）。

**易錯點**：以為「心臟有孔洞，血會兩邊都流」—— 不會，**淨流動方向由壓力差決定**，一側壓力較高就往那邊流。

**先分清「關節」與「肌腱」的功能**：

```
關節（joint）：两块骨之间可活动的连接处
  組成：骨（骨節面）、關節軟骨、關節囊、關節滑膜、滑液、**韌帶**

肌腱（tendon）：把**肌肉**連接到**骨**的構造
  → 屬於肌肉骨骼系統，但**不是關節的組成部分**
```

逐項檢查：

- **(1) 骨 —— 對**。關節由**兩塊（或多塊）骨的關節面**構成，骨是不可或缺的組成部分 → ✓
- **(2) 肌腱 —— 錯**。肌腱連接的是「**肌肉 ↔ 骨**」，作用是「**傳遞肌肉收縮的力量**」；而**韌帶**連接的是「**骨 ↔ 骨**」，作用是「**加強關節、防止脫位**」。肌腱不屬於關節 → ✗
- **(3) 韌帶 —— 對**。韌帶由緻密結締組織構成，強韆地把相鄰的骨連在一起，穩固關節 → ✓

→ **B（只有 (1) 和 (3)）**。

**肌腱 vs 韌帶（必考對比）**：

| | 韌帶（ligament） | 肌腱（tendon） |
|---|---|---|
| 連接 | **骨 ↔ 骨** | **肌肉 ↔ 骨** |
| 功能 | 穩固關節、防止脫位 | 傳遞肌肉收縮力 |
| 組織 | 緻密結締組織（膠原纖維多） | 緻密結締組織 |
| 受傷 | 扭傷（韌帶撕裂） | 拉傷／肌腱斷裂 |

**易錯點**：把「都是連接組織」當成「都是關節的一部分」。判別方法很簡單：**看它連的是什麼** —— 連骨與骨 = 韌帶（關節的成員）；連肌肉與骨 = 肌腱（不屬關節）。

@@@Q 27 2022
**這題考「控制變項」，判斷標準只有一句**：

> **凡是會影響所研究的依變項的因素，都必須保持不變。**

本題研究的是**光合作用速率**，所以：所有能影響光合作用速率的因素都要固定。

逐項檢查：

- **(1) pH —— 要保持不變**。pH 影響**酶的活性**（卡爾文循環的每一個步驟都由酶催化）。偏離最適 pH → 酶活性下降 → 光合速率下降 → 是干擾變數 ✓
- **(2) 溫度 —— 要保持不變**。溫度同樣影響**酶的催化速率**（在最適溫度前隨溫度上升而加快，過高則變性）→ ✓
- **(3) 光照強度 —— 要保持不變**。光照決定**光反應**的速率，進而決定供應給卡爾文循環的 **ATP 與 NADPH** 多寡 → ✓

三者**都會直接改變光合作用速率**，因此在本實驗中**全部都必須控制不變** → **D**。

**光合作用速率的四大限制因素（記住這張圖就會做這類題）**：

```
光合速率 = f( 光照強度 , CO₂ 濃度 , 溫度 , 水 )
              │          │          │       └ 水的供應（氣孔開度）
              ↓          ↓          ↓
          光反應     碳固定      酶活性
        (ATP/NADPH) (RuBP酶)   (所有步驟)
```

**答題技巧**：
- 研究「X 對光合速率的影響」→ X 是**自變項**，其餘全部是**控制變項**。
- 若題目問「哪些必須保持不變」，就找**所有會影響光合速率的因素**，而不是只有「比較明顯」的（很多人只想到光照，漏掉 pH 和溫度）。

**易錯點**：以為「pH 對植物影響不大」—— 植物細胞內的 pH 對酶活性極其敏感，碳酸鈣之類的緩衝物質（如土壤中的碳酸氫鈣）能穩定根際 pH，正是為了維持養分溶解度與酶活性。

**角質層的特性**：由**角質與蠟質**組成，**不透水**（防止水分散失）、對光**透明**（不阻擋光線）、可防病原體侵入。

逐項檢查：

- **A 減少水分流失 —— 正確**。角質層是植物體表的**防水層**，能大幅降低**蒸騰作用**造成的水分散失，也是陸生植物能適應乾燥環境的關鍵 ✓
- **B 讓光線通過 —— 錯**。角質層**確實是透明的**（不會擋光），但「透明」是它的**性質**，不是它的**功能**。它的主要功能是**防水**；「讓光線通過」是葉片整體（表皮無色透明）自然達成的效果，不是角質層的職責。
- **C 保護葉免受感染 —— 錯**。抵禦病原體主要靠**細胞壁**（物理屏障）、**表皮的完整性**以及**植物的化學防禦**（蠟質、酚類物質、抗菌物質）。角質層的主要功能是防水，不是防感染。
- **D 提高光合作用速率 —— 錯**。角質層不透水，恰恰**限制**了 CO₂ 進入葉片與水蒸氣散失；它**降低**而不是提高光合速率（雖然因減少失水而維持了葉片的水分狀態，間接有利，但這不是它的主要功能）。

→ **A**。

**易錯點（這題的陷阱在 B）**：
- 「角質層透明，所以功能是讓光線通過」—— 混淆了**性質**與**功能**。判斷功能時要問：**如果拿掉它，植物會出什麼問題？** 拿掉角質層 → 植物失水乾死 → 功能是**防水**。

**延伸**：角質層越厚的植物越耐旱（如松樹、仙人掌）；水生植物的角質層很薄或沒有。

**先做滲透判斷（方向與終點）**：

```
透析管內：2% 蔗糖溶液  → 水勢較高
透析管外：10% 蔗糖溶液 → 水勢較低（濃度高）
        ↓
水由高水勢流向低水勢 → 水**淨流出**透析管
        ↓
**兩支管的液面都下降**
```

**接著比較兩個裝置**。原卷裝置圖顯示：**裝置 2 的透析管更長**（袋子延伸到杯底），裝置 1 的較短。

```
透析管越長 → 膜的**表面積越大** → 每單位時間通過的水越多
        ↓
裝置 2：失水更快、更多 → 液面下降得更低，且更早達到平衡
裝置 1：失水較慢、較少 → 液面下降得較少
```

**所以正確圖形必須是**：兩條曲線都**下降**；**裝置 2 的曲線在下方**（降得更多）且**更早趨平**。

逐項核對原卷四幅圖：

- **A**：實線＝裝置 1 降得**更多**、虛線＝裝置 2 降得較少 → **把兩者對調了**。裝置 2 的管更長，應該降得更多才對 → ✗
- **B —— 正確**。實線＝裝置 1（下降較少、較晚趨平），虛線＝裝置 2（**下降更多、更早趨平**），符合「管越長、失水越多」→ ✓
- **C**：兩條曲線都**上升** → 方向錯了。水是流出透析管，液面應該下降 → ✗
- **D**：兩條曲線也都**上升** → 同上 → ✗

→ **B**。

**易錯點（這題的核心）**：沒有認清**哪個裝置的透析管更長**，就會選 A。解題順序應該是：
1. 先判**方向**（下降，因為管外濃度高）→ 排除 C、D；
2. 再判**哪個降得多**（管長、膜面積大者降得多）→ 在 A、B 之間選出 B。

@@@Q 36 2022
**先想清楚升溫會改變什麼、又不會改變什麼**。

溫度由 25 °C 升到 40 °C：

| | 影響 | 原因 |
|---|---|---|
| **水的運動速率** | **加快** | 溫度越高，分子的平均動能越大，擴散越快 |
| **滲透的方向** | 不變 | 由**濃度差**決定，與溫度無關 |
| **最終平衡位置** | **不變** | 平衡時兩側濃度相等，與溫度無關 |

**所以正確曲線的特徵**：40 °C 的曲線**下降得更快、更早趨平**，但最後與 25 °C **匯合於同一個平衡高度**（因為同樣是 2% 與 10% 的濃度差，最終平衡點相同）。

逐項核對原卷四幅圖：

- **A —— 正確**。實線＝25 °C（緩慢下降），虛線＝40 °C（**下降更快、先趨平，最後與 25 °C 匯合**）→ ✓
- **B**：40 °C（虛線）最終位置**比 25 °C 更低**，沒有匯合 → 錯（平衡位置不該隨溫度改變）
- **C**：兩條曲線都**上升** → 方向錯了
- **D**：兩條曲線也都**上升** → 方向錯了

→ **A**。

**關鍵概念：動態平衡與平衡位置**：

```
溫度 ↑ → 達到平衡「更快」（速率變快）
        → 但平衡「位置不變」（由濃度差決定）
        ↓
所以圖上必須是：兩條線最終匯合在同一高度，
      只是 40 °C 那條先抵達。
```

**易錯點**：以為「升溫 → 水跑得更快 → 流失更多 → 最終液面更低」。這是本題最容易犯的錯 —— **滲透是雙向的**：溫度高時水分子雙向往來都更快，但**淨移動的方向仍由濃度差決定**，所以平衡時兩側濃度相同、液面回到同一位置。

**延伸**：這也解釋了為什麼透析用於血液透析時要維持**體溫**：溫度影響速率，但不改變最終的清除效果。
