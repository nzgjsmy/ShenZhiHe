**先理解「為什麼不能同時做」的生理機制**：

```
吞嚥時：會厭（epiglottis）蓋住氣管開口 → 氣管封閉 → 空氣不能進出喉部
        ↓
說話需要：空氣由肺 → 氣管 → 喉頭 → 振動聲帶 → 發聲
        ↓
氣管一封閉，空氣到不了喉頭 → 發不出聲
```

- **(1) 對**：吞嚥時**會厭**（喉頭蓋）會蓋住氣管的開口，氣管與外界隔絕，空氣無法通過。
- **(3) 對**：說話（發聲）必須讓空氣**流經喉頭**、使**聲帶振動**。氣管被封閉後，空氣到不了喉頭，自然發不出聲。
- **(2) 錯**：「吞嚥是反射作用、說話是隨意動作」這句話**本身是對的**，但它**不能解釋**為什麼兩者不能同時進行。反射 vs 隨意是「控制方式」的差異，不是「能否並行」的機制。

→ **B（只有 (1) 和 (3)）**。

**這題的答題陷阱**：題目問的是「哪些**解釋**了不能同時進行」，不是「哪些陳述是正確的」。凡是**正確但不相關**的敘述（如 (2)），就要排除。檢查方法：**把這一項拿掉，結論還成立嗎？** 拿掉 (2)，「不能同時吞嚥和說話」依然成立 → (2) 不是解釋。

**延伸**：會厭蓋住氣管是**吞嚥反射**的一部分。嬰兒因為會厭功能未完全成熟，有時奶水會誤入氣管而嗆咳。

**華生與克里克的 DNA 雙螺旋模型有四項核心主張**，本題逐項考：

```
① 兩條多核苷酸鏈**互相纏繞成雙螺旋**
② 兩條鏈的**走向相反**（一條 5′→3′、另一條 3′→5′）—— 這就是「反向平行」
```

- **B 錯**：構成鏈（骨架）的是**脫氧核糖與磷酸基**交替連接；**鹼基並不連接成鏈**，而是由骨架向內伸出，靠氫鍵與對側鏈的鹼基配對。

- **D 錯**：DNA 的磷酸基只有**一種**。有**四種**的是**含氮鹼基**（A、T、G、C），不是磷酸基。

→ **A**。

**記憶對照表**：

| 組成 | DNA | RNA |
|---|---|---|
| 糖 | 脫氧核糖（1 種） | 核糖（1 種） |
| 磷酸基 | 1 種 | 1 種 |
| 鹼基 | **4 種**（A T G C） | **4 種**（A U G C） |

**易錯點**：這題把「鹼基、磷酸、糖」三者故意互換位置設陷阱 —— 記牢 **「DNA = 糖、磷酸各一種，鹼基四種」**。

**根尖由下而上分四區**（從根尖最前端往根的成熟方向）：

```
根尖
  │
  ├─ 根冠           （最前端，保護作用，像筆套）

        │
        └─ 根毛：表皮細胞向外突出，擴大吸收表面積
```

```
只有「已分化」的細胞才能執行吸收功能
        ↓
分化區的表皮細胞 → 具吸收功能 → 伸出根毛 → 面積大增 → 吸收效率大增
        ↓

```

@@@Q 30 2020
**關鍵是要分清「非特異性防禦」與「特異性免疫（免疫記憶）」**。

```
非特異性防禦（先天性，不專一，無記憶）        特異性免疫（後天性，專一，有記憶）
─────────────────────────────────────      ────────────────────────────
吞噬作用（巨噬細胞、嗜中性球）               記憶細胞 ← 本題答案
炎症反應（紅、腫、熱、痛）                   抗體
補體、溶菌酶、皮膚屏障                       殺手 T 細胞
```

逐項檢查：

- **A 吞噬作用**：屬**非特異性防禦**。它能吞噬病原體，但**不針對特定抗原**，也不留下「記憶」—— 沒有免疫記憶就不構成「免疫力」。
- **B 炎症**：屬**非特異性防禦**，是受損後的通用反應（血管擴張、通透性增加），非專一。
- **C 記憶細胞（答案）**：**免疫記憶**的物質基礎。當同一抗原再次入侵時，記憶細胞能迅速增殖並分化成漿細胞（產生大量抗體）與效應細胞，把病原體在發病前就壓制下去。這正是「免疫力」的定義 —— 對特定抗原的**專一性**與**持久性**。
- **D 血凝塊的形成**：屬於防止失血的**止血機制**（血液凝固），與抵抗病原體的免疫反應無關。

→ **C**。

**疫苗的原理正是利用這一點**：

```
接種疫苗 → 初次免疫反應 → 產生記憶細胞（＋少量抗體）
        ↓
日後真的感染同一病原體
        ↓
記憶細胞迅速大量增殖 → 二次免疫反應（抗體多、來得快、維持久）
        ↓
在症狀出現前就擊退病原體 → 「免疫力」
```

**易錯點**：以為「吞噬作用＝免疫力」。吞噬作用是**第一道防線**，人人都有、不分抗原；而「免疫力」在課本的定義裡特指**專一性的免疫記憶**。
